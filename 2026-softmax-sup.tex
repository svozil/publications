\section*{Overview}
This document presents the complete, verbatim source code for the formal verification accompanying the main manuscript. The executable project workspace is permanently archived on Zenodo at \url{https://doi.org/10.5281/zenodo.20479152} and can be cross-referenced with the active development repository.

This formalized supplement provides a complete machine-checked proof certificate for all finite claims concerning context-wise gluing, generalized-softmax coordinates, and the boundary bounds of the pentagon half-weight. The entire codebase has been fully verified using the Lean 4 interactive theorem prover (\texttt{v4.30.0}) and its standard mathematical library, mathlib (\texttt{v4.30.0}). The project compiles successfully via the standard \texttt{lake build} workflow; the underlying source text contains no logical gaps, placeholders (\texttt{sorry}, \texttt{admit}), or additional unvetted foundational assumptions (\texttt{axiom}).

The formalization separates three layers:
\begin{itemize}
    \item First, Section~\ref{app:lean-core} (\texttt{Core.lean}) defines finite event structures, admissible weights, positive coordinates, and the representation theorem for scaled link-function preimages.
    \item Second, Section~\ref{app:lean-gluing} (\texttt{Gluing.lean}) formalizes local context-wise distributions, single-valuedness, the normalizer-ratio calculation, and the theorem that single-valued local distributions glue to a global admissible weight.
    \item Third, Section~\ref{app:lean-pentagon} (\texttt{Pentagon.lean}) formalizes the pentagon example: the half-weight is admissible, every two-valued state and every finite classical mixture obeys the cyclic bound \(2\), the half-weight has cyclic sum \(5/2\), and \(5/2>\sqrt 5\). The same file also verifies the positive softmax-coordinate path and its boundary endpoint at the half-weight.
\end{itemize}
