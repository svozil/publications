\begin{abstract}
In the projection lattice of a finite-dimensional Hilbert space, an
orthogonal basis---a \emph{context}---is characterised by the property
that its atomic probabilities sum to one on every state.  We study a
weakening of this condition in which two tuples of atoms induce the same
probability sum on every state.  Such pairs are called
\emph{pseudocontexts}.  In finite dimension this is equivalent to two
distinct rank-one decompositions of the same positive operator, placing
the notion naturally among finite frame-theoretic constructions.  Size
$k=1$ is trivial; size $k=2$ already admits genuinely nonorthogonal
examples over~$\mathbb{C}$; and, in fact, examples exist for every
$k\ge 2$.  For $k\ge 3$, genuine pseudocontexts also exist over
$\mathbb{R}$.  We present the operator formulation, give a general
explicit construction, analyse the spectral structure of the associated
structure operator, illustrate the symmetric $k=3$ case with a~figure,
and list the remaining classification problems.
\end{abstract}

\keywords{projection lattice, pseudocontext, rank-one decomposition,
structure operator, quantum contextuality}

\section{Introduction}
% ------------------------------------------------------------------

Let $L$ be the lattice of projections in a %complex
Hilbert space of
finite dimension $n\ge 2$.  Its atoms (minimal non-zero elements)
correspond to one-dimensional subspaces, represented by nonzero
vectors.  States are described by probability measures
$P\colon L\to[0,1]$.  We denote by $S(L)$ the set of all states
on~$L$.

Vectors $a_1,\ldots,a_n$ form a \emph{context} if they compose an
orthogonal basis.  In this case (and only in this case) they satisfy
\begin{equation}
  \forall P\in S(L):\quad \sum_{i=1}^{n}P(a_i)=1.
  \label{eq:context}
\end{equation}
The present note concerns weaker additive identifications obtained by
comparing two tuples of atoms that are not required to be orthogonal.
Such \emph{pseudocontexts} are quantum-logical shadows of
orthomodular-lattice constructions of Mayet--Navara--Rogalewicz
\cite{Mayet_2000} and have direct physical meaning: they encode
state-independent empirical equivalences between families of generally
noncommuting observables.  It is then natural to ask for which sizes
$k$ and over which scalar fields genuine pseudocontexts exist.  The
answer is simple: pseudocontexts already exist for $k=2$ over
$\mathbb{C}$, and, more generally, for every $k\ge 2$; for $k\ge 3$
they exist over $\mathbb{R}$ as well.  Table~\ref{tab:existence}
summarises the existence landscape used below; ``genuine'' is understood
in the supporting-subspace sense made precise in
Definition~\ref{def:pc}.

\begin{table*}[t]

\label{tab:existence}
\centering
\footnotesize
\begin{tabular}{@{}llll@{}}
\toprule

\midrule

\section{Preliminaries}
% ------------------------------------------------------------------

Throughout, $H$ is a %complex
Hilbert space of finite dimension
$n\ge 2$, and $L=L(H)$ is the orthomodular lattice of its closed
subspaces.  Its atoms correspond to one-dimensional subspaces, or
equivalently to \emph{rays} spanned by nonzero vectors.  We identify
an atom with any representative unit vector $a$ and write
$P_a=|a\rangle\langle a|$ for the orthogonal projection onto the ray
it spans.  More generally, for nonzero $a$ we set $P_a=|a\rangle\langle
a|/\langle a,a\rangle$, so that $P_a$ depends only on the ray $\mathbb
C a$.

A \emph{state} is a map $P\colon L\to[0,1]$ with $P(I)=1$ that is
finitely additive on orthogonal families.  In dimension $n\ge 3$,
Gleason's theorem \cite{Gleason} asserts that every state arises from
a density operator $\rho$ via
\begin{equation}
  P(a)=\operatorname{tr}(\rho P_a),\qquad
  \rho\ge 0,\quad\operatorname{tr}\rho=1.
  \label{eq:gleason}
\end{equation}
For $n=2$, Gleason's theorem fails for the abstract definition of a
state, and we adopt~\eqref{eq:gleason} as the definition: a state is
the assignment $P_a\mapsto\operatorname{tr}(\rho P_a)$ for some density
operator $\rho$.  Under either reading, the key consequence we use
repeatedly is that two self-adjoint operators that agree on every
state are equal as operators (the density operators in finite
dimension separate self-adjoint operators).

\section{Contexts and pseudocontexts}
% ------------------------------------------------------------------

The operator form of \eqref{eq:context} is elementary and is the
starting point for everything that follows.

\begin{proposition}[Contexts]\label{prop:context}
Unit vectors $a_1,\ldots,a_n\in H$ form an orthonormal basis if and
only if
\begin{equation}
  \sum_{i=1}^{n}P_{a_i}=I.
  \label{eq:context-op}
\end{equation}
\end{proposition}

\begin{proof}
The forward implication is immediate.  For the converse, fix $j$ and
evaluate \eqref{eq:context-op} on the vector $a_j$:
\[
  1=\langle a_j,I\,a_j\rangle=\sum_{i=1}^{n}|\langle a_i,a_j\rangle|^2.
\]
The term with $i=j$ already contributes $1$, so all others must vanish.
Hence $\langle a_i,a_j\rangle=0$ for $i\neq j$.  As this holds for
every $j$, the family is orthonormal, and being of size $n$ in an
$n$-dimensional space it is an orthonormal basis.
\end{proof}

Combined with \eqref{eq:gleason}, Proposition~\ref{prop:context}
recovers \eqref{eq:context} as a state-theoretic characterisation of
orthogonal bases.

\begin{definition}[Pseudocontext]\label{def:pc}
Let $k\ge 1$.  A \emph{pseudocontext of size $k$} is a pair of
$k$-tuples of atoms $(a_1,\ldots,a_k)$, $(b_1,\ldots,b_k)$ such that
\begin{enumerate}
  \item[(i)]  each tuple contains pairwise distinct atoms (i.e.\ no
              two of the $a_i$ are scalar multiples, and likewise for
              the $b_i$),
  \item[(ii)] the two tuples are disjoint as sets of rays, so that
              $|\{a_1,\ldots,a_k,b_1,\ldots,b_k\}|=2k$, and
  \item[(iii)] $\displaystyle\forall P\in S(L):\quad
               \sum_{i=1}^{k}P(a_i)=\sum_{i=1}^{k}P(b_i)$.
\end{enumerate}
A pseudocontext is called \emph{genuine} if neither $k$-tuple is a
context on its supporting subspace, i.e. if the rays in neither tuple
form an orthonormal basis of their span.
\end{definition}

\begin{remark}
Condition~(i) excludes repeated atoms within a single tuple, and
condition~(ii) ensures the two tuples are truly distinct as collections
of rays. Without condition~(ii), every pseudocontext of size $k$
would yield pseudocontexts of every size $k'>k$ by adjoining $k'-k$
shared atoms; this trivial inflation can be carried out within the
original ambient subspace.
Condition~(ii) rules out such
padding and makes the size $k$ a genuine invariant of the construction.
\end{remark}

\begin{remark}[Contexts on supporting subspaces]
Accordingly, in the examples below the word ``context'' is often used in
the relative sense of an orthonormal basis of the supporting subspace on
which the construction lives. The ambient Hilbert space may be larger.
\end{remark}

By \eqref{eq:gleason}, condition~(iii) of Definition~\ref{def:pc} is
equivalent to the operator identity
\begin{equation}
  T:=\sum_{i=1}^{k}P_{a_i}=\sum_{i=1}^{k}P_{b_i},
  \label{eq:opid}
\end{equation}
which we call the \emph{structure operator} of the pseudocontext.
Thus pseudocontexts are precisely pairs of distinct unit-norm rank-one
decompositions of a single positive operator.  This places them
naturally among finite frame-theoretic constructions: contexts are the
special case in which the structure operator is the identity on the
relevant subspace; in general, pseudocontexts are unit-norm rank-one
frame decompositions of a common positive operator.  If the common
operator is proportional to the identity on its support, the family
is a tight frame; after normalisation on that support one obtains a
POVM\@.

\begin{remark}[Connection to SIC-POVMs]
If the common structure operator satisfies $T=\frac{k}{n}I$ and $k=n^2$, then
a single family $\{P_{a_1},\ldots,P_{a_k}\}$ scaled by $n/k$ is a SIC-POVM
exactly when the frame vectors are equiangular. Pseudocontexts are more
general: they concern two distinct unit-norm decompositions of the same
positive operator, without requiring equiangularity or the SIC cardinality
$k=n^2$.
\end{remark}

\section{The smallest cases}
% ------------------------------------------------------------------

We begin by proving the first three entries of
Table~\ref{tab:existence}: size $k=1$ is impossible, size $k=2$
exists over $\mathbb{C}$, and size $k=2$ has no genuine real
realisation.
\subsection{No pseudocontexts of size \texorpdfstring{$k=1$}{k=1}}

\begin{proposition}[Size $k=1$]\label{prop:k1}
There is no pseudocontext of size $k=1$.
\end{proposition}

\begin{proof}
The condition $P(a_1)=P(b_1)$ for all $P\in S(L)$ means that the two
self-adjoint operators $P_{a_1}$ and $P_{b_1}$ have equal expectation
in every density operator.  In finite dimension, density operators
separate self-adjoint operators, so $P_{a_1}=P_{b_1}$.  This rank-one
identity forces $a_1$ and $b_1$ to span the same ray, contradicting
the distinctness condition~(ii) of Definition~\ref{def:pc}.
\end{proof}


% ------------------------------------------------------------------
\subsection{Pseudocontexts of size \texorpdfstring{$k=2$}{k=2} and the Bloch representation}
\label{sec:d2}
% ------------------------------------------------------------------

In dimension two the pseudocontext condition admits a~complete
characterisation in terms of Bloch vectors.  This yields a unified and
basis-independent description of all pseudocontexts and clarifies the
real--complex dichotomy.

Every rank-one projector on $\mathbb{C}^2$ can be written as
\begin{equation}
  P_a=\tfrac{1}{2}\bigl(I+\vec{r}_a\cdot\vec{\sigma}\bigr),
  \qquad \vec{r}_a\in\mathbb{R}^3,\quad \|\vec{r}_a\|=1,
  \label{eq:bloch}
\end{equation}
where $\vec{\sigma}=(\sigma_x,\sigma_y,\sigma_z)$ are the Pauli
matrices.  To be specific, for any unit vector $a=\alpha e_1+\beta e_2
\in\mathbb{C}^2$ in a chosen orthonormal basis $(e_1,e_2)$, the
components of the associated Bloch vector $\vec{r}_a=(r_x,r_y,r_z)$
are obtained by computing the expectation values of the Pauli
matrices:
\begin{align}
  r_x &= \langle a,\sigma_x a\rangle = 2\operatorname{Re}(\alpha^*\beta), \notag \\
  r_y &= \langle a,\sigma_y a\rangle = 2\operatorname{Im}(\alpha^*\beta),
        \label{eq:bloch_components} \\
  r_z &= \langle a,\sigma_z a\rangle = |\alpha|^2-|\beta|^2. \notag
\end{align}

\begin{proposition}[Bloch representation of pseudocontexts in dimension $d=2$]
\label{prop:bloch_pc}
Let $(a_1,\ldots,a_k)$ and $(b_1,\ldots,b_k)$ be two tuples of unit vectors in
$\mathbb{C}^2$ satisfying the distinctness/disjointness conditions of
Definition~\ref{def:pc}(i)--(ii). Then the following are equivalent:
\begin{enumerate}
    \item condition~(iii) of Definition~\ref{def:pc} holds;
    \item $\displaystyle\sum_{i=1}^{k}P_{a_i}
            = \sum_{i=1}^{k}P_{b_i}$;
    \item $\displaystyle\sum_{i=1}^{k}\vec{r}_{a_i}
            = \sum_{i=1}^{k}\vec{r}_{b_i}$.
\end{enumerate}
The common structure operator $T$ has Bloch form
\[
  T=\tfrac{k}{2}I+\tfrac{1}{2}\,\vec{R}\cdot\vec{\sigma},
  \qquad \vec{R}=\sum_{i=1}^{k}\vec{r}_{a_i}
              =\sum_{i=1}^{k}\vec{r}_{b_i}.
\]
\end{proposition}

\begin{proof}
By Definition~\ref{def:pc} and~\eqref{eq:opid}, conditions~1 and~2 are
equivalent. For the equivalence with~3, substitute the Bloch representation
\eqref{eq:bloch} into the structure operator:
\[
  \sum_{i=1}^{k}P_{a_i}
  =\sum_{i=1}^{k}\tfrac{1}{2}\bigl(I+\vec{r}_{a_i}\cdot\vec{\sigma}\bigr)
  =\tfrac{k}{2}I+\tfrac{1}{2}\Bigl(\sum_{i=1}^{k}\vec{r}_{a_i}\Bigr)
   \cdot\vec{\sigma}.
\]
Since $I,\sigma_x,\sigma_y,\sigma_z$ are linearly independent, equality of
the two structure operators is equivalent to equality of the Bloch-vector sums.
\end{proof}

% ------------------------------------------------------------------
\subsection{Explicit \texorpdfstring{$k=2$}{k=2} example via Bloch vectors}
\label{sec:d2_example}
% ------------------------------------------------------------------

We can now construct an explicit $k=2$ pseudocontext by directly
applying the Bloch representation and showing exactly how it arises
from non-orthogonal configurations.

\begin{proposition}[Existence of $k=2$ complex pseudocontexts]\label{prop:k2c}
There are genuinely nonorthogonal pseudocontexts of size ${k=2}$ in
$\mathbb{C}^n$ for every $n\ge 2$.
\end{proposition}

\begin{proof}
Embed $\mathbb{C}^2$ into $\mathbb{C}^n$ as the span of the first two
basis vectors $e_1,e_2$.  Define two pairs of unit vectors:
\[
  u_\pm=\Bigl(\tfrac{\sqrt{3}}{2},\,\pm\tfrac{1}{2},\,0,\ldots,0\Bigr),
  \qquad
  v_\pm=\Bigl(\tfrac{\sqrt{3}}{2},\,\pm\tfrac{i}{2},\,0,\ldots,0\Bigr).
\]
We obtain their Bloch vectors explicitly using
\eqref{eq:bloch_components}.  For $u_\pm$, setting
$\alpha=\sqrt{3}/2$ and $\beta=\pm 1/2$, we compute:
\begin{align*}
  r_x &= 2\operatorname{Re}\bigl(\tfrac{\sqrt{3}}{2}\cdot
         (\pm\tfrac{1}{2})\bigr) = \pm\tfrac{\sqrt{3}}{2}, \\
  r_y &= 2\operatorname{Im}\bigl(\tfrac{\sqrt{3}}{2}\cdot
         (\pm\tfrac{1}{2})\bigr) = 0, \\
  r_z &= \bigl|\tfrac{\sqrt{3}}{2}\bigr|^2
         -\bigl|\pm\tfrac{1}{2}\bigr|^2
       = \tfrac{3}{4}-\tfrac{1}{4} = \tfrac{1}{2}.
\end{align*}
Thus $\vec{r}_{u_\pm}=(\pm\frac{\sqrt{3}}{2},0,\frac{1}{2})$, which
lie in the $xz$-plane of the Bloch sphere.

For $v_\pm$, setting $\alpha=\sqrt{3}/2$ and $\beta=\pm i/2$,
we have $\alpha^*\beta = (\sqrt{3}/2)(\pm i/2)$, so:
\begin{align*}
r_x &= 2\operatorname{Re}({\textstyle\frac{\sqrt3}{2}}\cdot{\textstyle\pm\frac{i}{2}}) = 0,\\
r_y &= 2\operatorname{Im}({\textstyle\frac{\sqrt3}{2}}\cdot{\textstyle\pm\frac{i}{2}}) = \pm\tfrac{\sqrt{3}}{2},\\
r_z &= \tfrac{3}{4}-\tfrac{1}{4}=\tfrac{1}{2}.
\end{align*}
Thus $\vec{r}_{v_\pm}=(0,\pm\frac{\sqrt{3}}{2},\frac{1}{2})$, which
lie in the $yz$-plane.

Summing the Bloch vectors within each pair yields the same structure
vector:
\[
  \vec{R}=\vec{r}_{u_+}+\vec{r}_{u_-}
        =\vec{r}_{v_+}+\vec{r}_{v_-}=(0,0,1).
\]
By Proposition~\ref{prop:bloch_pc}, this guarantees that the operator
sums match in the two-dimensional subspace.  Embedding back into
$\mathbb{C}^n$ gives, with $V:=\mathrm{span}\{e_1,e_2\}$,
\begin{align}
  &P_{u_+}+P_{u_-}=P_{v_+}+P_{v_-}
   =\tfrac{3}{2}P_{e_1}+\tfrac{1}{2}P_{e_2}\nonumber\\
  &\;=\bigl(I_V+\tfrac{1}{2}\sigma_z\bigr)\oplus 0_{n-2}
   =\begin{pmatrix}3/2&0\\0&1/2\end{pmatrix}\oplus 0_{n-2}.\nonumber
\end{align}
The four rays are distinct: $u_+$ and $u_-$ differ by a sign in the
real second coordinate; $v_+$ and $v_-$ differ by a sign in the
imaginary second coordinate.
No \(u_\pm\) is collinear with any \(v_\pm\): comparison of the first
coordinate forces the proportionality scalar to be \(1\), but then the
second coordinates are different.
Within each pair, $\langle u_+,u_-\rangle=\tfrac{1}{2}\neq 0$ and
$\langle v_+,v_-\rangle=\tfrac{1}{2}\neq 0$, so neither pair is
orthogonal.  The pseudocontext is therefore genuine.
\end{proof}

\begin{remark}[Bloch geometry of the complex $k=2$ example]
This construction directly illustrates the continuous $U(1)$ freedom
present in complex spaces.  The pair of Bloch vectors
$\{\vec{r}_{v_+},\vec{r}_{v_-}\}$ is related to
$\{\vec{r}_{u_+},\vec{r}_{u_-}\}$ by a $90^\circ$ rotation about the
$z$-axis (which aligns with their common sum~$\vec{R}$).  Because this
rotation preserves $\vec{R}$, it produces a distinct, valid
decomposition of the same fixed structure operator~$T$.
\end{remark}


\subsection{Classification in $\mathbb{C}^2$}

Pseudocontexts in dimension two correspond exactly to distinct
decompositions of a fixed vector $\vec{R}\in\mathbb{R}^3$ into $k$
unit vectors.

\begin{theorem}[Complete characterisation in $\mathbb{C}^2$]
\label{thm:d2_complex}
Let $k\ge 1$.
\begin{enumerate}
\item[(i)] For $k=1$, no pseudocontext exists.
\item[(ii)] For $k=2$, pseudocontexts exist and form continuous families.
\item[(iii)] For all $k\ge 3$, pseudocontexts exist; if $\vec{R}=0$,
they arise from zero-centroid configurations (e.g.\ regular polygons).
\end{enumerate}
\end{theorem}

\begin{proof}
Part (i) is Proposition~\ref{prop:k1}.

For (ii), fix $\vec{R}\in\mathbb{R}^3$ with $0<\|\vec{R}\|<2$.  Writing
\[
  \vec{r}_1=\vec{R}/2+\vec{w},\qquad
  \vec{r}_2=\vec{R}/2-\vec{w},
\]
the condition $\|\vec{r}_1\|=\|\vec{r}_2\|=1$ is equivalent to
$\vec{w}\perp\vec{R}$ and $\|\vec{w}\|^2=1-\|\vec{R}\|^2/4$.
Thus $\vec{w}$ ranges over a circle in the plane orthogonal to $\vec{R}$,
so the set of unordered pairs $\{\vec{r}_1,\vec{r}_2\}$ is a continuous
family.

For (iii), choose any $k\ge 3$ and take a regular $k$-gon on a great circle
of the Bloch sphere. Let $(a_1,\ldots,a_k)$ be its corresponding rays in
$\mathbb{C}^2$, and let $(b_1,\ldots,b_k)$ be the image under a rotation
not belonging to the finite symmetry group of that $k$-gon. For a generic
choice of rotation, the two ray sets are disjoint. Both $k$-tuples have the
same centroid $0$, hence the same structure operator, and because $k\ge 3$
neither tuple is a context. Therefore they form a genuine pseudocontext.
\end{proof}


\subsection{Real--complex dichotomy in two dimensions}

The $k=2$ complex example in Proposition~\ref{prop:k2c} is the simplest
continuous family. In $\mathbb{R}^2$, no genuine pseudocontext of size
$k=2$ exists, as stated in Theorem~\ref{thm:d2_real_complex}(ii) below.

\begin{theorem}[Real vs.\ complex in $d=2$]
\label{thm:d2_real_complex}
$\;$
\begin{enumerate}
\item[(i)] In $\mathbb{C}^2$, genuine pseudocontexts of size $k=2$
exist.
\item[(ii)] In $\mathbb{R}^2$, no genuine pseudocontext of size $k=2$
exists.
\item[(iii)] In $\mathbb{R}^2$, genuine pseudocontexts exist for all
$k\ge 3$.
\end{enumerate}
\end{theorem}

\begin{proof}
Part (i) follows from Proposition~\ref{prop:k2c}.

For (ii), represent a real ray by a unit vector
\(x_\theta=(\cos\theta,\sin\theta)\), with angles understood modulo
\(\pi\).  Its projector is
\[
  P_\theta=\frac12
  \begin{pmatrix}
  1+\cos 2\theta & \sin 2\theta\\
  \sin 2\theta & 1-\cos 2\theta
  \end{pmatrix}.
\]
Thus a real ray is parametrised by the doubled-angle unit vector
\(q_\theta=(\cos2\theta,\sin2\theta)\), and equality
\(P_{\theta_1}+P_{\theta_2}=P_{\phi_1}+P_{\phi_2}\) is equivalent to
\(q_{\theta_1}+q_{\theta_2}=q_{\phi_1}+q_{\phi_2}\).
If this common sum is nonzero, a two-term decomposition of it into
unit vectors in the plane is unique up to permutation, so the two
unordered pairs of rays coincide.  If the common sum is zero, then
\(q_{\theta_2}=-q_{\theta_1}\), hence the two corresponding rays are
orthogonal; the pair is a context on its two-dimensional support.
In either case no genuine real pseudocontext of size \(2\) exists.

For (iii), choose distinct real rays with angles
\[
  \theta_j=\theta_0+\frac{\pi j}{k},\qquad j=0,\ldots,k-1.
\]
Their doubled-angle vectors form a regular \(k\)-gon and therefore
have centroid \(0\).  A second copy rotated by an angle
\(\delta\not\equiv m\pi/k\pmod{\pi}\) for all \(m\in\mathbb Z\)
is disjoint from the first one and has the same centroid.  The two
projector sums are consequently equal, and since \(k\ge3\) neither
tuple is an orthonormal basis of its two-dimensional support.  Hence
the two tuples form a genuine pseudocontext.
\end{proof}

\begin{remark}[Earlier observation]\label{rem:realvscomplex}
The nonexistence of genuine real pseudocontexts of size $k=2$ in
dimension two was observed in~\cite{NSvozil:QS24} without noticing
that the situation is different in complex spaces.  The doubled-angle (real Bloch-circle) parametrisation makes the real--complex dichotomy transparent: over $\mathbb{R}$
a decomposition of a fixed structure operator into two rank-one terms
is unique up to permutation, whereas over $\mathbb{C}$ a continuous
phase degree of freedom produces inequivalent decompositions.
\end{remark}

\begin{proposition}\label{prop:no_real_k2_anyn}
No genuine pseudocontext of size \(k=2\) exists over a real Hilbert space
of any finite dimension.
\end{proposition}

\begin{proof}
Suppose
\[
P_{a_1}+P_{a_2}=P_{b_1}+P_{b_2}=:T
\]
with all vectors real and unit. The range of \(T\) is
\[
\operatorname{span}\{a_1,a_2\}=\operatorname{span}\{b_1,b_2\},
\]
so all four rays lie in a subspace of dimension at most two. If this
subspace is one-dimensional, distinctness fails. Hence we may restrict to
a real two-dimensional support.

If \(a_1\perp a_2\), then \(T\) acts as the identity on its
2-dimensional support. Proposition~\ref{prop:context}, applied within
that support, then implies that any two-vector unit decomposition of the
identity is an orthonormal basis of the support; so both pairs are
contexts and the pseudocontext is not genuine.

If \(a_1\) and \(a_2\) are not orthogonal, choose their signs so that
\(\gamma=\langle a_1,a_2\rangle\in(0,1)\). Then \(T\) has the simple
eigenvalues \(1+\gamma\) and \(1-\gamma\), with eigenvectors proportional
to \(a_1+a_2\) and \(a_1-a_2\). These spectral data determine the unordered
pair of rays \(\{[a_1],[a_2]\}\) uniquely. Hence any other real
decomposition of \(T\) into two unit rank-one projections gives the same
two rays up to permutation, contradicting the disjointness requirement.
Therefore no genuine real size-two pseudocontext exists.
\end{proof}

\subsection{Spectral form}

\begin{proposition}[Spectrum in $d=2$]
\label{prop:d2_spectrum}
The eigenvalues of $T$ are
\[
  \lambda_{\pm}=\tfrac{k}{2}\pm\tfrac{1}{2}\|\vec{R}\|.
\]
\end{proposition}

\begin{remark}
The vector $\vec{R}$ completely parametrises pseudocontexts in
dimension two.
\end{remark}

\section{Pseudocontexts of every size
         \texorpdfstring{$k\ge 2$}{k>=2}}
\label{sec:allk}
% ------------------------------------------------------------------

The $k=2$ case is best understood via the Bloch-sphere parametrisation;
the general $k$-construction below is its root-of-unity extension.  This
section supplies the complex existence row of Table~\ref{tab:existence}
for all $k\ge2$.  The construction below uses a continuous phase
$e^{i\phi}$ and is therefore intrinsically complex; the corresponding
existence statement over $\mathbb{R}$ for $k\ge 3$ is covered separately
by Example~\ref{ex:mb} in Section~\ref{sec:symk3}.

\begin{theorem}[Complex-phase construction]\label{thm:allk}
Let $H$ contain an orthonormal pair $e_1,e_2$.  Fix an integer
$k\ge 2$, let $\omega=e^{2\pi i/k}$, choose $\alpha\in(0,\pi/2)$, and
choose $\phi\in\mathbb{R}$ such that $e^{i\phi}$ is not a $k$th root
of unity.  Define unit vectors
\begin{align*}
  a_j &= \cos\alpha\,e_1+\sin\alpha\,\omega^j e_2,\\
  b_j &= \cos\alpha\,e_1+\sin\alpha\,e^{i\phi}\omega^j e_2,
  \qquad j=0,\ldots,k-1.
\end{align*}
Then the $2k$ rays spanned by the $a_j$ and $b_j$ are pairwise
distinct, and
\[
  \sum_{j=0}^{k-1}P_{a_j}=\sum_{j=0}^{k-1}P_{b_j}
  =k\bigl(\cos^2\!\alpha\;P_{e_1}+\sin^2\!\alpha\;P_{e_2}\bigr).
\]
Hence $(a_0,\ldots,a_{k-1})$ and $(b_0,\ldots,b_{k-1})$ form a
pseudocontext of size $k$.  If $\alpha\neq\pi/4$, then the
pseudocontext is genuine.
\end{theorem}

\begin{proof}
Write $c=\cos\alpha$ and $s=\sin\alpha$.  For each $j$,
\begin{align*}
  P_{a_j} &= c^2 P_{e_1}+s^2 P_{e_2}
             +cs\bigl(\omega^{-j}|e_1\rangle\langle e_2|
                     +\omega^{j}|e_2\rangle\langle e_1|\bigr),\\
  P_{b_j} &= c^2 P_{e_1}+s^2 P_{e_2}
             +cs\bigl(e^{-i\phi}\omega^{-j}|e_1\rangle\langle e_2|
                     +e^{i\phi}\omega^{j}|e_2\rangle\langle e_1|\bigr).
\end{align*}
Summing over $j=0,\ldots,k-1$ and using $\sum_{j=0}^{k-1}\omega^j=0$
cancels all off-diagonal terms, giving
\[
  \sum_{j=0}^{k-1}P_{a_j}=\sum_{j=0}^{k-1}P_{b_j}
  =k\bigl(c^2 P_{e_1}+s^2 P_{e_2}\bigr).
\]

\textit{Distinctness.}
If $a_j=\lambda a_\ell$ for some scalar $\lambda$, then comparing
first coordinates (which equal $c\neq 0$) gives $\lambda=1$, and then
$\omega^j=\omega^\ell$, so $j=\ell$.  Hence the $a_j$ are pairwise
distinct rays; the identical argument applies to the $b_j$.  If
$a_j=\lambda b_\ell$, then $\lambda=1$ and
$\omega^j=e^{i\phi}\omega^\ell$, i.e.\ $e^{i\phi}=\omega^{j-\ell}$,
contradicting the assumption that $e^{i\phi}$ is not a $k$th root of
unity.  Hence no $a_j$ coincides with any $b_\ell$.

\textit{Genuineness.}
For $j\neq\ell$ within the $a$-tuple,
\[
  \langle a_j,a_\ell\rangle = c^2+s^2\omega^{\ell-j}.
\]
This vanishes only if $c^2=s^2$ (i.e.\ $\alpha=\pi/4$) and
$\omega^{\ell-j}=-1$.  So for $\alpha\neq\pi/4$, no two distinct
vectors in the $a$-tuple are orthogonal.  An identical computation
gives $\langle b_j,b_\ell\rangle=c^2+s^2\omega^{\ell-j}$, so the same
conclusion holds for the $b$-tuple.  Hence neither tuple is a context
when $\alpha\neq\pi/4$.
\end{proof}

\begin{remark}[Complex versus real constructions]
Theorem~\ref{thm:allk} uses a genuinely complex phase. The real examples
in Example~\ref{ex:mb} and Section~\ref{sec:3d_real} are different
mechanisms and should not be conflated with the root-of-unity family.
\end{remark}

\begin{remark}\label{rem:tight}
At the special value $\alpha=\pi/4$, the structure operator becomes
$\frac{k}{2}I_{\mathrm{span}\{e_1,e_2\}}$, so the construction yields
a unit-norm tight frame on the two-dimensional support.  For $k=2$
this reduces to a context; for $k\ge 3$ it gives a highly symmetric
pseudocontext (cf.\ Remark~\ref{rem:trine}).  In dimension $d=2$,
this construction reduces to the Bloch-vector description of
Sec.~\ref{sec:d2}.
\end{remark}

\section{A symmetric \texorpdfstring{$k=3$}{k=3} example}
\label{sec:symk3}
% ------------------------------------------------------------------

The case $k=3$ admits a very transparent planar representation; it is
the finite-dimensional analogue of the Mercedes--Benz frame.

\begin{example}[Mercedes--Benz type pseudocontext]\label{ex:mb}
Fix a two-dimensional subspace $V\subset H$ with orthonormal basis
$(e_1,e_2)$, and fix an angle $\theta$ satisfying
$\theta\not\equiv 0$, $\theta\not\equiv\pi/3$, and
$\theta\not\equiv 2\pi/3$ modulo~$\pi$.
Put, for $j=0,1,2$,
\[
  a_j=\cos\!\Bigl(\tfrac{2\pi j}{3}\Bigr)e_1
     +\sin\!\Bigl(\tfrac{2\pi j}{3}\Bigr)e_2,
\]
\[
  b_j=\cos\!\Bigl(\tfrac{2\pi j}{3}+\theta\Bigr)e_1
     +\sin\!\Bigl(\tfrac{2\pi j}{3}+\theta\Bigr)e_2.
\]
Then the six rays are pairwise distinct, and
\[
  \sum_{j=0}^{2}P_{a_j}=\sum_{j=0}^{2}P_{b_j}=\tfrac{3}{2}I_V.
\]
Thus $(a_0,a_1,a_2)$ and $(b_0,b_1,b_2)$ form a genuine
pseudocontext of size $k=3$ over $\mathbb{R}$.
\end{example}

\begin{proof}
In the basis $(e_1,e_2)$, each projector has the form
\[
  P_{\cos\varphi\,e_1+\sin\varphi\,e_2}
  =\begin{pmatrix}\cos^2\!\varphi&\cos\varphi\sin\varphi\\
                  \cos\varphi\sin\varphi&\sin^2\!\varphi\end{pmatrix}.
\]
For $\varphi_j=2\pi j/3$ and for $\varphi_j=\theta+2\pi j/3$, the
trigonometric identities
\[
  \sum_{j=0}^{2}\cos(2\varphi_j)=0,\qquad
  \sum_{j=0}^{2}\sin(2\varphi_j)=0,
\]
which hold for any arithmetic progression of three angles spaced
$2\pi/3$ apart, imply that the off-diagonal terms cancel while the
diagonal terms each sum to $3/2$.  Hence both sums equal
$\frac{3}{2}I_V$.

The three excluded residue classes modulo~$\pi$ account for all
collisions between the two triples:
\begin{itemize}
  \item $\theta\equiv 0\pmod{\pi}$: every $b_j$ coincides with $a_j$
        or $-a_j$, giving the same ray.
  \item $\theta\equiv\pi/3\pmod{\pi}$: the $b$-triple is a cyclic
        permutation of the $a$-triple as a set of rays.
  \item $\theta\equiv 2\pi/3\pmod{\pi}$: the $b$-triple is again a
        permutation of the $a$-triple.
\end{itemize}
For all other values of $\theta$, the six rays are pairwise distinct.
Genuineness holds because for generic $\theta$ no two vectors within
the same triple are orthogonal (the angle between consecutive vectors
in each triple is $2\pi/3\neq\pi/2$), so neither triple is a context.
\end{proof}

\begin{remark}[Complex trine description]\label{rem:trine}
Example~\ref{ex:mb} has a~compact complex analogue.  Let
$\omega=e^{2\pi i/3}$ and embed $V$ into $\mathbb{C}^n$ as
$\mathrm{span}\{e_1,e_2\}$.  The \emph{trines}
\[
  u_j=\tfrac{1}{\sqrt{2}}\bigl(1,\omega^j,0,\ldots,0\bigr),\;
  v_j=\tfrac{1}{\sqrt{2}}\bigl(1,e^{i\phi}\omega^j,0,\ldots,0\bigr),
\]
with $j=0,1,2$, yield another rank-one decomposition of the same
structure operator $\tfrac{3}{2}I_V$ for any $\phi\in\mathbb{R}$
that is not a multiple of $2\pi/3$.  The identity
$1+\omega+\omega^2=0$ makes the off-diagonal entries of
$\sum_j P_{u_j}$ and $\sum_j P_{v_j}$ cancel, giving the common
structure operator $\frac{3}{2}I_V$.  This form is most natural in
frame-theoretic discussions and in connection with the
Weyl--Heisenberg group.
\end{remark}

\begin{remark}[Minimal ambient dimension]\label{rem:minimaldim}
The explicit constructions in Sections~\ref{sec:d2}, \ref{sec:allk}, and
\ref{sec:symk3} all live in the two-dimensional subspace
$\mathrm{span}\{e_1,e_2\}$, so they embed into any $\mathbb{C}^n$ or
$\mathbb{R}^n$ with $n\ge 2$. This is a statement about the constructions
exhibited here, not about all pseudocontexts in all dimensions; indeed,
the rotational construction of Section~\ref{sec:3d_real} produces real
pseudocontexts whose rays span all of $\mathbb{R}^n$. No
pseudocontext exists in dimension $n=1$, since there is only one ray.
\end{remark}

\begin{remark}[Nondegenerate structure operators]\label{rem:nondegenerate}
The trine family is highly symmetric: its structure operator is a
scalar multiple of the identity on its support.  More complicated
examples with nondegenerate structure operators occur already in
dimension three.
The main difference is
that the pseudocontext in Example~\ref{ex:mb} has only one constant
value in the probability sum, while the advanced constructions admit
a larger range of values, still respecting the equality.
%
Explicit three-dimensional implementations of nondegenerate structure
operators were derived in \cite{2023-navara-svozil}.

\begin{itemize}

\item \textbf{15-atom hypergraph ($T_1$).}  A pseudocontext of size
  ${k=3}$
  yields
  \(
    \lambda_1=2\),
  \(\lambda_2=\tfrac{7+\sqrt{21}}{14}\approx 0.827\),
 \(\lambda_3=\tfrac{7-\sqrt{21}}{14}\approx 0.173\),
  with $\operatorname{tr}(T_1)=3$ and $\lambda_{\max}=2>1$, consistent
  with Proposition~\ref{prop:strict}.

\item \textbf{36-atom hypergraph ($T_2$).}  A larger true-implies-false

\end{itemize}

Such
examples are useful when one wants to move beyond purely symmetric
frame orbits.
\end{remark}

\section{Spectral structure and canonical forms}
\label{sec:spectral}
% ------------------------------------------------------------------

In dimension $d=2$, all spectral properties reduce to the Bloch form
of Sec.~\ref{sec:d2}.  We now analyse the general properties of the
structure operator $T=\sum_{i=1}^{k}P_{a_i}$ associated with a
$k$-tuple of unit vectors $(a_1,\ldots,a_k)$ in $H$.

\subsection{Gram representation and spectral equivalence}

\begin{definition}[Analysis operator and Gram matrix]
Let $A\colon\mathbb{C}^k\to H$ be defined by $Ae_i=a_i$, where $(e_i)$
is the standard basis of $\mathbb{C}^k$.  The \emph{analysis operator}
is $A^\dagger\colon H\to\mathbb{C}^k$, and the \emph{Gram matrix} is
\[
  G:=A^\dagger A=\bigl(\langle a_i,a_j\rangle\bigr)_{i,j=1}^k.
\]
\end{definition}

\begin{proposition}[Frame operator factorisation]\label{prop:AAstar}
The structure operator admits the factorisation $T=AA^\dagger$, and
$G=A^\dagger A$.
\end{proposition}

\begin{proposition}[Spectral equivalence]\label{prop:spectral_equivalence}
The nonzero spectra of $T$ and $G$ coincide (including
multiplicities):
\[
  \sigma(T)\setminus\{0\}=\sigma(G)\setminus\{0\}.
\]
In particular, $\mathrm{rank}(T)=\mathrm{rank}(G)\le\min(k,n)$.
\end{proposition}

\begin{proof}
This is the standard singular-value correspondence between
$AA^\dagger$ and $A^\dagger A$: if $AA^\dagger v=\lambda v$ with
$\lambda\neq 0$, then $A^\dagger A(A^\dagger v)=\lambda(A^\dagger v)$
and $A^\dagger v\neq 0$.
\end{proof}

\subsection{Spectral constraints}

\begin{proposition}[Trace identities]\label{prop:trace}
The structure operator satisfies
\[
  \operatorname{tr}(T)=k,\qquad
  \operatorname{tr}(T^2)=\sum_{i,j=1}^{k}|\langle a_i,a_j\rangle|^2.
\]
The diagonal terms $i=j$ each contribute $1$, giving
$\operatorname{tr}(T^2)\ge k$, with equality if and only if the
vectors are mutually orthogonal.
\end{proposition}

\begin{proof}
$\operatorname{tr}(T)=\sum_i\operatorname{tr}(P_{a_i})=k$.  For the
second identity,
$\operatorname{tr}(T^2)=\sum_{i,j}\operatorname{tr}(P_{a_i}P_{a_j})
=\sum_{i,j}|\langle a_i,a_j\rangle|^2$.  Diagonal terms contribute~$k$;
off-diagonal terms are non-negative, and vanish simultaneously
if and only if all off-diagonal inner products are zero.
\end{proof}

\begin{proposition}[Non-orthogonality and maximal eigenvalue]
\label{prop:strict}
If the vectors $(a_i)$ are not mutually orthogonal, then
$\operatorname{tr}(T^2)>k$ and $\lambda_{\max}(T)>1$.  If, in addition,
the nonzero spectrum of $T$ is flat on its support of rank $r$, then
$T=(k/r)I_{\operatorname{supp}T}$ and necessarily $k>r$.
\end{proposition}

\begin{proof}
The strict trace inequality is Proposition~\ref{prop:trace}.  If all
eigenvalues of $T$ were at most $1$, then
$\operatorname{tr}(T^2)\le \operatorname{tr}(T)=k$, a contradiction.
Thus $\lambda_{\max}(T)>1$.  The final assertion follows by writing a
flat nonzero spectrum as $k/r,\ldots,k/r$.
\end{proof}

\begin{proposition}[Majorisation constraint]\label{prop:maj}
Suppose $k\le n$.  Let $\lambda(T)=(\lambda_1,\ldots,\lambda_n)$ be
the eigenvalues of $T$ in decreasing order (padded with zeros to
length $n$), and let $d=(1,\ldots,1,0,\ldots,0)\in\mathbb{R}^n$ have
$k$ ones and $n-k$ zeros.  Then $\lambda(T)\succ d$.
\end{proposition}

\begin{proof}
The diagonal entries of $G$ are $G_{ii}=\|a_i\|^2=1$, so the diagonal
of $G$ is $(1,\ldots,1)\in\mathbb{R}^k$.  By the Schur--Horn theorem,
$\lambda(G)\succ(1,\ldots,1)$.  Since $G$ and $T$ share the same
nonzero eigenvalues
(Proposition~\ref{prop:spectral_equivalence}), padding $\lambda(G)$
with $n-k$ zeros gives $\lambda(T)$, and $\lambda(T)\succ d$ follows.

\smallskip\noindent\textit{Overcomplete case $k>n$.}  When $k>n$ the
Gram matrix $G$ is $k\times k$ with rank at most $n$; the
majorisation is then best stated for the $k$-dimensional eigenvalue
vector of $G$ against $(1,\ldots,1)\in\mathbb{R}^k$, and the
Schur--Horn argument applies to $G$ directly.
\end{proof}

\begin{proposition}[Operator bounds]\label{prop:bounds}
The structure operator satisfies $0\le T\le kI$.  Moreover, if
$\mu:=\max_{i\neq j}|\langle a_i,a_j\rangle|$, then
\[
  \lambda_{\max}(T)\le 1+(k-1)\mu.
\]
\end{proposition}

\begin{proof}
Positivity $T\ge 0$ is immediate, and $T\le kI$ since each
$P_{a_i}\le I$.  For the eigenvalue bound, apply the Ger\v{s}gorin
circle theorem to $G$: since $G_{ii}=1$ and $|G_{ij}|\le\mu$ for
$i\neq j$, every eigenvalue of $G$ lies in a disk centred at $1$ with
radius at most $(k-1)\mu$.  Since the nonzero eigenvalues of $T$ and
$G$ coincide, $\lambda_{\max}(T)\le 1+(k-1)\mu$.
\end{proof}

\subsection{Commutant and symmetry}

\begin{definition}[Commutant]
The \emph{unitary commutant} of $T$ is
$\mathcal{C}(T):=\{U\in U(H):UT=TU\}$.
\end{definition}

\begin{proposition}[Structure of the commutant]\label{prop:commutant}
Let $T=\sum_\alpha\lambda_\alpha P_\alpha$ be the spectral
decomposition of $T$ with distinct eigenvalues $\lambda_\alpha$ and
orthogonal projections $P_\alpha$ of ranks $m_\alpha$.  Then
$\mathcal{C}(T)\cong\prod_\alpha U(m_\alpha)$.
\end{proposition}

\begin{remark}
Spectral degeneracies ($m_\alpha>1$) give rise to commutant-generated
continuous families of distinct rank-one decompositions of $T$ (as in
tight frames).  A simple spectrum removes this particular symmetry
source, although residual decomposition moduli may still occur, as the
complex $k=2$ example already illustrates.  This explains why the
tight-frame case (Remark~\ref{rem:tight}) is especially rich in
pseudocontexts.
\end{remark}

\subsection{Canonical normal form}

\begin{proposition}[Spectral normal form]\label{prop:normalform}
Every structure operator is unitarily equivalent to
$\mathrm{diag}(\lambda_1,\ldots,\lambda_r,0,\ldots,0)$ with
$\lambda_i>0$, $\sum_{i=1}^r\lambda_i=k$, and
$r=\mathrm{rank}(T)$.
\end{proposition}

\subsection{Canonical parametrisation of all decompositions}

\begin{theorem}[Canonical decomposition]\label{thm:canonical}
Let $T$ be a positive operator of rank $r$ with spectral decomposition
$T=\sum_{i=1}^{r}\lambda_i|e_i\rangle\langle e_i|$, $\lambda_i>0$, and
set $\Lambda=\mathrm{diag}(\lambda_1,\ldots,\lambda_r)$.  For a
decomposition into $k$ unit vectors, the rank condition $k\ge r$ is
necessary, but existence also depends on the usual finite-frame
Schur--Horn majorisation constraints.

Every rank-one decomposition $T=\sum_{j=1}^{k}P_{a_j}$ with
$\|a_j\|=1$ corresponds to a matrix $C\in\mathbb{C}^{r\times k}$
satisfying
\begin{equation}
  CC^\dagger=\Lambda,\qquad \|c_j\|^2=1\;\text{ for all }j,
  \label{eq:Ccond}
\end{equation}
where $c_j$ is the $j$-th column of $C$, via
$a_j=\sum_{i=1}^{r}c_{ij}e_i$.  Conversely, every such $C$ defines a
valid decomposition.
\end{theorem}

\begin{proof}
Let $T=AA^\dagger$ with columns $a_j$.  In the eigenbasis of $T$,
write $A=UC$ where $U$ is the unitary embedding the eigenbasis of $T$
on its support into $H$.  Then
$CC^\dagger=U^\dagger TU\big|_{\mathrm{supp}(T)}=\Lambda$, and
$\|c_j\|=\|a_j\|=1$.  The converse is a direct computation.
\end{proof}

\begin{corollary}[Unitary freedom]\label{cor:unitary}
Among all rank-one decompositions $T=\sum_{j=1}^{k}|a_j\rangle\langle
a_j|$ into $k$ \emph{not necessarily} unit-norm vectors, any two are
related by $A\mapsto AU$ for some $U\in U(k)$ (this is the standard
$U(k)$-orbit on the affine fibre $\{A:AA^\dagger=T\}$).  The
unit-norm constraint $\|c_j\|=1$ in~\eqref{eq:Ccond} cuts out a
generically real-codimension-$k-1$ subvariety of this orbit (one of the $k$ norm equations is redundant because $\operatorname{tr}T=k$), and what is relevant
for pseudocontexts is the quotient by phases acting on individual
columns and by permutations of columns, since rays---not vectors---are
the data.
\end{corollary}

\subsection{Characterisation of pseudocontexts}

\begin{proposition}[Operator equivalence criterion]\label{prop:pseudo_equiv}
Two $k$-tuples $(a_1,\ldots,a_k)$ and $(b_1,\ldots,b_k)$ of distinct rays form
a~pseudocontext if and only if their matrices $C_A,C_B$ in the
eigenbasis of $T$ both satisfy~\eqref{eq:Ccond}:
\[
  C_A C_A^\dagger=C_B C_B^\dagger=\Lambda.
\]
\end{proposition}

\begin{remark}
Pseudocontexts correspond to distinct points in the space
$\{C\in\mathbb{C}^{r\times k}:CC^\dagger=\Lambda,\,\|c_j\|=1\}/{\sim}$,
where $\sim$ identifies decompositions that yield the same set of
rays.
\end{remark}

\subsection{Extremal spectral bounds}

\begin{proposition}[Rayleigh bounds]\label{prop:rayleigh}
For any density operator~$\rho$,
\[
  \lambda_{\min}(T)\le\operatorname{tr}(\rho T)\le\lambda_{\max}(T).
\]
Both bounds are tight, achieved by pure states on the corresponding
eigenvectors of $T$.
\end{proposition}

\section{Topological Forcing vs. Algebraic Coincidence: The Problem of ``Loose Ends''}
\label{sec:loose_ends}
% ------------------------------------------------------------------

The discrepancy between the purely geometric validity of the $k=2$ complex pseudocontext and the failure of its orthogonality hypergraph to enforce it highlights a fundamental distinction in quantum contextuality. We categorize pseudocontexts into two types: those that are \emph{graph-forced} (topologically necessitated by the hypergraph) and those that are \emph{algebraic coincidences} (contingent upon specific vector representations).

\subsection{Graph-forced pseudocontexts}

For certain tightly intertwined hypergraphs, the completeness condition $P(I) = 1$ is sufficient to structurally force a pseudocontext identity. The covering technique---as demonstrated in the octagon hypergraph---utilizes this. By summing the completeness conditions of selected contexts, one creates two distinct ``coverings'' of the hypergraph. If the multiplicities of the vertices in both coverings match perfectly, then any variable appearing in both sums must have an equal probability contribution. In such cases, the equality of the probability sums is a rigid, state-independent logical necessity of the hypergraph, applying equally to all probability assignments, whether classical or quantum.

\subsection{Algebraic coincidences: the $k=2$ case}

The $k=2$ complex pseudocontext formed by $u_\pm$ and $v_\pm$ (Proposition~\ref{prop:k2c}) does not admit this topological forcing. Because \(u_+\) and \(u_-\) are not orthogonal, they cannot belong to the
same context. To use context-completeness equations, each ray must instead
be completed separately to an orthonormal basis by adding auxiliary rays.
The resulting auxiliary vertices are loose ends unless the hypergraph
contains further contexts forcing their contributions to cancel.

Consequently, classical $\{0,1\}$-valuations can assign truth values that violate the pseudocontext identity. The equality $\sum P(u_\pm) = \sum P(v_\pm)$ holds for these specific quantum observables solely due to their vector representation (the structure operator $T$ being identical for both sets), not due to the logical skeleton of their orthogonalities.

To achieve a structurally forced pseudocontext---where the identity is dictated purely by the graph---we require configurations without such loose ends. This necessitates higher-dimensional hypergraphs where pseudocontextuality is embedded directly into the orthomodular logic, effectively closing the ``loose ends'' that prevent the covering technique from succeeding in simpler cases.


\section{The Octagon Pseudocontext via Distinct Coverings}
\label{s:octagon}

We can rigorously demonstrate the pseudocontextual nature of a tightened---relative to the previous configuration involving $u_\pm$ and $v_\pm$---octagon hypergraph by employing a proof technique based on mutually distinct ``coverings,'' a method we previously utilized in \cite{NSvozil:QS24}.

The hypergraph consists of 20 vertices and 12 contexts of size three. We label the 16 outer vertices along the perimeter as follows: let $v_0, v_1, \ldots, v_7$ be the midpoints of the eight octagon edges, and let $v_{01}, v_{12}, \ldots, v_{70}$ be the eight corners. The perimeter is formed by eight straight-line contexts:
\begin{equation*}
    E_i = \{v_{i-1, i},\; v_i,\; v_{i, i+1}\} \quad \text{for } i=0,\dots,7 \pmod 8.
\end{equation*}
Notice that adjacent midpoints, such as $v_1$ and $v_2$, are not on the same context; rather, their respective perimeter contexts $E_1$ and $E_2$ intertwine at the shared corner vertex $v_{12}$.

The remaining four inner contexts connect opposite midpoints and pass through the four inner vertices $a_1, a_2$ and $b_1, b_2$:
\begin{align*}
    D_0 &= \{v_0, a_1, v_4\}, \quad D_2 = \{v_2, a_2, v_6\}, \\
    D_1 &= \{v_1, b_2, v_5\}, \quad D_3 = \{v_3, b_1, v_7\}.
\end{align*}

We aim to prove that the sums of probabilities on the inner pairs match: $P(a_1)+P(a_2) = P(b_1)+P(b_2)$. To do so, we construct two distinct coverings of the hypergraph.

\textbf{Covering A} focuses on the first pseudocontext pair $\{a_1, a_2\}$, as depicted in Fig.~\ref{fig:octagon_coverings}(a). We construct it by taking the inner contexts $D_0, D_2$ along with four alternating perimeter edges:
\begin{equation*}
    A = \{D_0, D_2, E_1, E_3, E_5, E_7\}.
\end{equation*}
Summing the completeness condition over these six contexts yields a total probability of 6. Let us evaluate the multiplicity of each vertex covered by $A$:
\begin{itemize}
    \item The inner vertices $a_1, a_2$ are covered exactly once.
    \item The midpoints $v_0, v_4$ and $v_2, v_6$ are covered exactly once (by $D_0, D_2$).
    \item The remaining midpoints $v_1, v_3, v_5, v_7$ are covered exactly once (by $E_1, E_3, E_5, E_7$).
    \item Each of the eight corners $v_{i, i+1}$ is covered exactly once because the selected alternating perimeter contexts perfectly span all corners without overlapping.
\end{itemize}
Thus, covering A perfectly partitions all 16 outer vertices, covering each exactly once:
\begin{equation}
    P(a_1) + P(a_2) + \sum_{i=0}^7 P(v_i) + \sum_{\text{corners}} P(v_{i, i+1}) = 6. \label{eq:covA}
\end{equation}

\textbf{Covering B} focuses on the second pseudocontext pair $\{b_1, b_2\}$, depicted in Fig.~\ref{fig:octagon_coverings}(b). We construct it using the other two inner contexts $D_1, D_3$ alongside the complementary set of four alternating perimeter edges:
\begin{equation*}
    B = \{D_1, D_3, E_0, E_2, E_4, E_6\}.
\end{equation*}
Summing over these six contexts also yields 6. Evaluating the vertex multiplicities reveals:
\begin{itemize}
    \item The inner vertices $b_1, b_2$ are covered exactly once.
    \item The midpoints $v_1, v_5$ and $v_3, v_7$ are covered exactly once (by $D_1, D_3$).
    \item The remaining midpoints $v_0, v_2, v_4, v_6$ are covered exactly once (by $E_0, E_2, E_4, E_6$).
    \item The selected perimeter contexts $E_0, E_2, E_4, E_6$ again perfectly span all eight corners exactly once.
\end{itemize}
Hence, Covering B covers the same set of 16 outer vertices, each exactly once:
\begin{equation}
    P(b_1) + P(b_2) + \sum_{i=0}^7 P(v_i) + \sum_{\text{corners}} P(v_{i, i+1}) = 6. \label{eq:covB}
\end{equation}

Subtracting \eqref{eq:covB} from \eqref{eq:covA}, all perimeter terms cancel
term by term, because each such vertex appears with the same multiplicity in
both coverings. The only uncancelled terms are $P(a_1)+P(a_2)$ and
$P(b_1)+P(b_2)$, hence
\[
    P(a_1)+P(a_2)=P(b_1)+P(b_2).
\]
This is the desired state-independent identity.

% ================================================================
\subsection{The parameter \(C\)}
\label{app:C}
% ================================================================

In the octagon coordinatization---that is, the search for a faithful orthogonal representation~\cite{lovasz-79} of the uniform hypergraph~\cite{Bretto-MR3077516} in which vectors assigned to adjacent vertices (or, more generally, to vertices within each hyperedge) are required to be orthogonal---it is convenient to parametrize the inner pair by a single positive parameter \(C\).
Since only rays matter, all vectors below are understood up to a nonzero scalar multiple.

\begin{proposition}[Meaning of the parameter \(C\)]
Let \(s>0\), set \(C:=s^2\), and choose representatives
\[
  a_1 =  (s,1,0),\qquad a_2 =  (s,-1,0),
\]
with companion rays
\[
  b_1 =  (s,i,0),\qquad b_2 =  (s,-i,0).
\]
Then the inner pair \(\{a_1,a_2\}\) has mutual angle \(2\alpha\)
satisfying
\[
  \cos(2\alpha)=\frac{C-1}{C+1},
  \qquad\text{equivalently}\qquad
  C=\cot^2\alpha.
\]
In particular, \(C=1\) is the orthogonal case.
\end{proposition}

\begin{proof}
The normalized representatives of \(a_1\) and \(a_2\) are
\[
  \frac{(s,1,0)}{\sqrt{s^2+1}},\qquad
  \frac{(s,-1,0)}{\sqrt{s^2+1}}.
\]
Their inner product equals \((s^2-1)/(s^2+1)\), which gives the
stated formula after substituting \(C=s^2\).  The same computation
applies to the \(b\)-pair.
\end{proof}

\begin{remark}
The point of the parameter \(C\) is that, in the explicit octagon
coordinatization used in the main text, the closure conditions depend
on the inner pair only through this single scalar.
\end{remark}

\begin{example}[Exact \(\mathbb C^3\) realization at \(C=1\)]
\label{ex:C1}
Let
\[
  p=\frac{\sqrt{14}+\sqrt{2}}{4},
  \qquad
  q=\frac{\sqrt{14}-\sqrt{2}}{4}.
\]
Then
\[
  p^2+q^2=2,
  \qquad
  pq=\frac34.
\]

A convenient choice of the inner rays intersection at the additional point $c=(0,0,1)$ is
\[
\begin{aligned}
  a_1 & =  (1,1,0), & a_2 & =  (1,-1,0),\\
  b_1 & =  (1,i,0), & b_2 & =  (1,-i,0).
\end{aligned}
\]

One compatible choice of the eight midpoint rays is
\[
\begin{aligned}
  v_0 & =  (1,-1,\sqrt2),       & v_4 & =  (1,-1,-\sqrt2),\\
  v_1 & =  (1,i,p+iq),          & v_5 & =  (1,i,-p-iq),\\
  v_2 & =  (1,1,-i\sqrt2),      & v_6 & =  (1,1,i\sqrt2),\\
  v_3 & =  (1,-i,q-ip),         & v_7 & =  (1,-i,-q+ip).
\end{aligned}
\]

One compatible choice of the eight corner rays is
\[
\begin{aligned}
  v_{01} & =  \bigl(-p+i(q+\sqrt2),\ \sqrt2-p+iq,\ 1-i\bigr),\\
  v_{12} & =  \bigl(\sqrt2-p+iq,\ p-i(q+\sqrt2),\ 1+i\bigr),\\
  v_{23} & =  \bigl(q+\sqrt2+ip,\ -q+i(\sqrt2-p),\ -1+i\bigr),\\
  v_{34} & =  \bigl(q+i(p-\sqrt2),\ q+\sqrt2+ip,\ -1-i\bigr),\\
  v_{45} & =  \bigl(p-i(q+\sqrt2),\ -\sqrt2+p-iq,\ 1-i\bigr),\\
  v_{56} & =  \bigl(-\sqrt2+p-iq,\ -p+i(q+\sqrt2),\ 1+i\bigr),\\
  v_{67} & =  \bigl(-q-\sqrt2-ip,\ q-i(\sqrt2-p),\ -1+i\bigr),\\
  v_{70} & =  \bigl(-q-i(p-\sqrt2),\ -q-\sqrt2-ip,\ -1-i\bigr).
\end{aligned}
\]

A direct symbolic check shows that each listed context is orthogonal.
The identities \(p^2+q^2=2\) and \(pq=\tfrac34\) are sufficient for
the simplification.  Hence the octagon from Section~\ref{s:octagon}
admits an exact \(\mathbb C^3\) realization at \(C=1\).
\end{example}

\begin{remark}
The coordinates above are not unique.  Any common unitary
transformation, together with arbitrary rescalings of the individual
ray representatives, yields an equivalent realization.
\end{remark}

\begin{remark}[Phase symmetry]
The exact \(\mathbb C^3\) realization exploits a complex phase
symmetry in the third coordinate.  This is one of the reasons why the
construction is much more rigid over \(\mathbb R\) than over
\(\mathbb C\).
\end{remark}





% ================================================================
\subsection{No faithful real realization at \(C=1\)}
\label{app:real}
% ================================================================

Example~\ref{ex:C1} provides an exact realization of the octagon hypergraph in \(\mathbb{C}^3\) at the orthogonal limit \(C=1\), where the inner pseudocontext splits into two contexts. We show that no faithful realization by real rays exists.

\begin{proposition}[No faithful real realization at \(C=1\)]
\label{prop:no_real_C1}
The octagon hypergraph of Section~\ref{s:octagon}, augmented by the two inner \(C=1\) contexts intersecting at the vertex \(c\), admits no faithful representation by rays in \(\mathbb{R}^3\).
\end{proposition}

\begin{proof}
Assume a faithful real realization exists. By a global orthogonal transformation, fix \(c=(0,0,1)^T\). All rays sharing a context with \(c\) lie in the \(xy\)-plane. Using rotational freedom in that plane, set
\[
  a_1=(1,0,0)^T,\qquad a_2=(0,1,0)^T.
\]
Let
\[
  b_1=(\cos\theta,\sin\theta,0)^T,\qquad b_2=(-\sin\theta,\cos\theta,0)^T,
\]
with \(\theta\notin \frac{\pi}{2}\mathbb{Z}\) by faithfulness. Define \(m=\tan\theta\neq 0\) and \(M=1+m^2>1\).

Let the midpoint rays be \(v_j=(X_j,Y_j,Z_j)^T\).

\medskip
\noindent\emph{Nonplanarity of midpoint rays.}
Every midpoint lies in exactly one inner context, paired with one of
the planar reference vectors:
\(v_0,v_4\in D_0\) (with \(a_1\));
\(v_2,v_6\in D_2\) (with \(a_2\));
\(v_1,v_5\in D_1\) (with \(b_2\));
\(v_3,v_7\in D_3\) (with \(b_1\)).
Suppose \(Z_j=0\), so that \(v_j\) lies in the \(xy\)-plane.
If \(v_j\) is paired with \(a_1\) (resp.\ \(a_2\)), orthogonality forces
\(X_j=0\) (resp.\ \(Y_j=0\)), leaving \(v_j\) proportional to \(a_2\)
(resp.\ \(a_1\)). If \(v_j\) is paired with \(b_1\) or \(b_2\), the
relations \(Y=mX\) or \(X=-mY\) together with \(Z_j=0\) force
coincidence with one of the \(b\)-rays. In every case this violates
faithfulness.
Hence \(Z_j\neq 0\) for all \(j\), and we may normalize
\[
  v_j=(X_j,Y_j,1)^T.
\]

The inner contexts impose:
\begin{align*}
D_0:&\quad X_0=X_4=0,\qquad Y_0Y_4+1=0,\\
D_1:&\quad Y_1=mX_1,\quad Y_5=mX_5,\quad X_1X_5 M+1=0,\\
D_3:&\quad X_3=-mY_3,\quad X_7=-mY_7,\quad Y_3Y_7 M+1=0.
\end{align*}
Thus
\[
  X_5=-\frac{1}{M X_1},\qquad Y_7=-\frac{1}{M Y_3}.
\]
The quantities \(X_1\) and \(Y_3\) are nonzero: if \(X_1=0\) (resp.\ \(Y_3=0\)),
then \(v_1\) (resp.\ \(v_3\)) becomes collinear with a coordinate direction,
forcing vertex identifications incompatible with faithfulness.

For perimeter contexts, the condition that adjacent corner rays are orthogonal yields
\[
  (v_{j-1}\cdot v_j)(v_j\cdot v_{j+1})-(v_{j-1}\cdot v_{j+1})\|v_j\|^2=0.
\]
Evaluating at \(j=0\) and \(j=4\) gives
\begin{equation}
Y_0 = \frac{Y_7+mX_1}{1-mX_1Y_7}, \qquad
Y_4 = \frac{Y_3+mX_5}{1-mY_3X_5}, \label{eq:Y0a4tight}
\end{equation}
where the denominators are nonvanishing: if \(1-mX_1Y_7=0\), the
closure equation at \(j=0\) reduces to \(Y_7+mX_1=0\), and combining
this with \(mX_1Y_7=1\) yields \(-m^2X_1^2=1\), which has no real
solution. The case \(1-mY_3X_5=0\) at \(j=4\) is excluded analogously.

\medskip\noindent
Substituting the inner relations into \eqref{eq:Y0a4tight}  and simplifying the compound fractions yields
\[
  Y_0=\frac{m M X_1Y_3-1}{M Y_3+mX_1},\qquad
  Y_4=\frac{M X_1Y_3-m}{M X_1+mY_3}.
\]
Using \(Y_0Y_4=-1\) from \(D_0\), set \(u=X_1Y_3\). Expanding the product of these fractions, collecting terms in \(u\), and applying the identity \(M=1+m^2\) causes all mixed terms to cancel, yielding the master constraint (see Appendix~\ref{app:master_derivation})
\begin{equation}
\label{eq:master}
(M^2 u^2 + m u + 1) + M(X_1^2+Y_3^2)=0.
\end{equation}

Since \(X_1,Y_3\in\mathbb{R}\),
\[
  X_1^2+Y_3^2 \ge 2|X_1Y_3|=2|u|,
\]
and therefore the left-hand side is bounded below by
\[
  f(u)=M^2 u^2 + m u + 1 + 2M|u|.
\]
Using \(M=1+m^2\), one has \(2M-|m|>0\), hence
\[
  M^2 u^2 + m u + 2M|u| \ge M^2 u^2 + |u|(2M-|m|)\ge 0,
\]
with equality only at \(u=0\). Consequently \(f(u)\ge 1\) for all \(u\in\mathbb{R}\), contradicting the required vanishing. Therefore no real realization exists.
\end{proof}

\begin{remark}[Minimality of the obstruction]
Of the fourteen orthogonality relations defining the \(C=1\) octagon,
the proof above invokes only the three inner contexts \(D_0\), \(D_1\),
\(D_3\) and the two perimeter closures at \(j=0\) and \(j=4\); the
remaining nine relations are not used. The impossibility therefore
holds already for this five-relation sub-pattern.
\end{remark}

\begin{remark}[Complex realization]
In the complex construction, one has formally \(m=i\), hence \(M=1+i^2=0\). The relations above then become singular, and the coercive quadratic structure responsible for the contradiction disappears. Substituting \(M=0\) reduces the constraint to \(iu+1=0\), which admits solutions in \(\mathbb{C}\).
\end{remark}



\begin{remark}
The paper~\cite{harding2025remarksIJTP}
 presented the first construction of an orthogonality (Greechie) diagram which can be represented by vectors in complex spaces, but not in real ones.
As a by-product of our effort,
we found another (and much simpler) such diagram described in this section.
\end{remark}

\section{Physical interpretation and constraints}
% ------------------------------------------------------------------

A pseudocontext $(a_1,\ldots,a_k)$, $(b_1,\ldots,b_k)$ implements a~state-independent
empirical equivalence between two families of rank-one observables
$A_i=P_{a_i}$ and $B_i=P_{b_i}$.  Although the operators within each
family are generally noncommuting, the two linear functionals
\[
  \rho\longmapsto\sum_i\operatorname{tr}(\rho A_i),\qquad
  \rho\longmapsto\sum_i\operatorname{tr}(\rho B_i)
\]
agree on the whole state space.

The spectral decomposition of $T$ establishes absolute quantum limits
on these probability sums.  By Proposition~\ref{prop:rayleigh},
\begin{equation}
  \lambda_{\min}(T)\le\sum_{i=1}^{k}P(a_i)\le\lambda_{\max}(T).
  \label{eq:qbounds}
\end{equation}
These bounds are tight.

For the 36-atom hypergraph example \cite{2023-navara-svozil}, the
structure operator $T_2=\mathrm{diag}(1/5,1/5,13/5)$ confines the
quantum probability sum to $[1/5,\,13/5]=[0.2,\,2.6]$.  A classical
hidden-variable model based on two-valued ($\{0,1\}$) truth
assignments to projections---subject to the consistency requirement
that exactly one atom in each orthogonal basis receives the
value~$1$---would allow the sum to range over $\{0,1,2,3\}$, which
includes the extreme values $0$ and $3$.  Because $T_2$ has no
eigenvalue equal to $0$ or $3$, quantum mechanics forbids these
extremes; the quantum system cannot reach them.  This discrepancy is
a signature of Kochen--Specker-type contextuality
\cite{cabello-96,kochen1}.

This state-independent additive equivalence is related to, but
distinct from, the operational notion of contextuality introduced by
Spekkens \cite{Spekkens-04}, which applies to arbitrary experimental
procedures (preparations, transformations, and unsharp measurements)
rather than to sharp projective measurements alone.  A precise
comparison is beyond the scope of this note.

In the language of quantum information, $(A_1,\ldots,A_k)$ and
$(B_1,\ldots,B_k)$ are distinct rank-one decompositions of the same
positive operator.  When this operator is proportional to the identity
on its support, the families form tight frames; after normalisation
they yield POVMs.

\section{Genuinely three-dimensional real pseudocontexts}
\label{sec:3d_real}
% ------------------------------------------------------------------

The constructions of Sections~\ref{sec:allk}--\ref{sec:symk3} produce
real pseudocontexts whose rays are confined to a two-dimensional
subspace.  We now exhibit the full-support tight-frame mechanism listed
in the final row of Table~\ref{tab:existence}.  It exploits the spectral
structure developed in Section~\ref{sec:spectral} and yields continuous
families of real pseudocontexts whose rays span all of $\mathbb{R}^n$.
The starting point is the observation that when the structure operator
$T$ is proportional to the identity, the unitary commutant
(Proposition~\ref{prop:commutant}) is the full orthogonal group, so every
spatial rotation produces a new rank-one decomposition of the same
operator.

\subsection{The rotation principle for tight frames}

\begin{proposition}[Rotation principle]\label{prop:rot_principle}
Let $(a_1,\ldots,a_k)$ be a unit-norm tight frame in $\mathbb{R}^n$ with pairwise distinct rays,
i.e.,
\[
  T=\sum_{i=1}^{k}P_{a_i}=\frac{k}{n}\,I_n.
\]
For every $R\in O(n)$, the rotated tuple $(Ra_1,\ldots,Ra_k)$ is
again a unit-norm tight frame with the same structure operator $T$.
The collision set
\[
  S^{*}=\bigl\{R\in O(n):[Ra_j]=[a_i]\text{ for some }i,j\bigr\}
\]
is a closed proper subvariety of $O(n)$ of codimension at least
$n-1$, and hence has Haar measure zero.  For every
$R\in O(n)\setminus S^{*}$ the $2k$ rays
$[a_1],\ldots,[a_k],[Ra_1],\ldots,[Ra_k]$ are pairwise distinct, and
the tuples $(a_1,\ldots,a_k)$ and $(Ra_1,\ldots,Ra_k)$ form a
pseudocontext of size $k$, genuine whenever $k>n$.
\end{proposition}

\begin{proof}
Conjugation by $R\in O(n)$ fixes any scalar multiple of the identity,
so $RTR^{T}=T$.  Since $P_{Ra_i}=R\,P_{a_i}\,R^{T}$, summing gives
$\sum_i P_{Ra_i}=RTR^{T}=T$, proving that the rotated tuple is a
unit-norm tight frame with the same structure operator.

For each ordered pair $(i,j)$ and each sign $\varepsilon\in\{\pm1\}$,
the locus $\{R\in O(n):Ra_j=\varepsilon a_i\}$ is a single coset of
the stabiliser $\mathrm{Stab}_{O(n)}(a_j)\cong O(n-1)$, hence a
closed submanifold of codimension $n-1$ in $O(n)$.  The collision
set $S^{*}$ is the finite union of these submanifolds, hence a
closed subvariety of codimension at least $n-1$ and Haar measure
zero.

For $R\in O(n)\setminus S^{*}$, no $Ra_j$ is collinear with any
$a_i$.  Since the original rays are pairwise distinct and rotations
preserve ray distinctness, the $2k$ rays are pairwise distinct.  When $k>n$, no
$k$-tuple of unit vectors in $\mathbb{R}^n$ can be orthogonal, so
neither tuple is a context, and the pseudocontext is genuine.
\end{proof}

\begin{remark}
The genericity condition $R\in O(n)\setminus S^{*}$ is mild: $S^{*}$
has Haar measure zero in $O(n)$, so a Haar-random rotation produces
a pseudocontext with probability one.  The valid parameter space
$O(n)\setminus S^{*}$ is open and dense, and itself a smooth
manifold of dimension $\binom{n}{2}$.
\end{remark}

\begin{remark}[Spectral interpretation]\label{rem:spectral_rot}
Proposition~\ref{prop:rot_principle} is the maximally degenerate
case of the unitary commutant analysis of
Section~\ref{sec:spectral}: when the spectrum of $T$ collapses to a
single eigenvalue, the commutant $\mathcal{C}(T)$ becomes the full
orthogonal group, and every rotation gives a fresh rank-one
decomposition.  This sharpens the informal observation made in
Remark~\ref{rem:tight} for the two-dimensional support of the trine:
tight frames are precisely the configurations whose pseudocontextual
partners form a continuous orbit under a continuous Lie group of
symmetries.
\end{remark}

\begin{corollary}[Spectrum of tight pseudocontexts]
\label{cor:tight_spectrum}
Let $n \ge 2$. A genuine pseudocontext with structure operator
$T = \lambda I_n$ exists if and only if $\lambda$ is of the form
\[
\lambda = \frac{k}{n}
\]
for some integer $k > n$.
\end{corollary}

\begin{proof}
If $T = \lambda I_n$ arises from a $k$-tuple of unit vectors,
then by Proposition~\ref{prop:trace},
\[
\operatorname{tr}(T) = k.
\]
Since $\operatorname{tr}(\lambda I_n) = n\lambda$, it follows that
$\lambda = k/n$.

Moreover, $\operatorname{rank}(T) = n$, while
$\operatorname{rank}(T) \le k$, hence $k \ge n$.
If $k = n$, then Proposition~\ref{prop:trace} implies that the
vectors are mutually orthogonal, so the tuple is a context rather
than a genuine pseudocontext. Thus $k > n$ is necessary.

Conversely, for every integer $k>n$ there exists a unit-norm tight
frame $(a_1,\dots,a_k)$ with pairwise distinct rays in $\mathbb{R}^n$
(and hence in $\mathbb{C}^n$) satisfying
\[
\sum_{i=1}^k P_{a_i} = \frac{k}{n} I_n.
\]
Proposition~\ref{prop:rot_principle} then implies that, for a generic
rotation $R \in O(n) \setminus S^{*}$, the tuple
$(Ra_1,\dots,Ra_k)$ yields a distinct decomposition of the same
operator. The two tuples therefore form a genuine pseudocontext.
\end{proof}

\begin{remark}[Discrete spectrum of tight operators]
The scalar $\lambda$ is constrained to the discrete set
\[
\lambda \in \left\{ \frac{k}{n} : k \in \mathbb{N},\ k > n \right\}.
\]
In particular, not every positive real value can occur.
For fixed dimension $n$, the admissible values form a
discrete subset of $(1,\infty)$; as $n$ varies, these
values become dense in $(1,\infty)$.
\end{remark}

\subsection{The tetrahedral pseudocontext}
\label{sec:tetrahedron}

The simplest nontrivial application of
Proposition~\ref{prop:rot_principle} in genuine three-dimensional
ambient space is provided by the regular tetrahedron, the unique
(up to orthogonal equivalence and relabeling) unit-norm tight frame
of size four in $\mathbb{R}^3$.

\begin{example}[Tetrahedral pseudocontext]\label{ex:tetrahedron}
Let
\begin{align*}
  a_1 &= (0,\,0,\,1),\\
  a_2 &= \bigl(\tfrac{2\sqrt{2}}{3},\,0,\,-\tfrac{1}{3}\bigr),\\
  a_3 &= \bigl(-\tfrac{\sqrt{2}}{3},\,\tfrac{\sqrt{6}}{3},\,-\tfrac{1}{3}\bigr),\\
  a_4 &= \bigl(-\tfrac{\sqrt{2}}{3},\,-\tfrac{\sqrt{6}}{3},\,-\tfrac{1}{3}\bigr)
\end{align*}
be the vertices of a regular tetrahedron inscribed in the unit
sphere of $\mathbb{R}^3$, satisfying $\langle a_i,a_j\rangle=-1/3$
for $i\neq j$.  Choose any $R\in SO(3)\setminus S^{*}$ (i.e.\ $R$ is
not a rotation that maps any $a_j$ onto an $\pm a_i$), and define
\[
  b_j:=Ra_j,\qquad j=1,\ldots,4.
\]
Then the eight rays
$[a_1],\ldots,[a_4],[b_1],\ldots,[b_4]$ are pairwise distinct, and
\[
  \sum_{j=1}^{4}P_{a_j}=\sum_{j=1}^{4}P_{b_j}=\tfrac{4}{3}\,I_3,
\]
so $(a_1,\ldots,a_4)$ and $(b_1,\ldots,b_4)$ form a genuine
pseudocontext of size $k=4$ in $\mathbb{R}^3$ whose eight rays span
all of $\mathbb{R}^3$.

A concrete instance is provided by the quarter-turn about the
$x$-axis,
\[
  R=\begin{pmatrix} 1 & 0 & 0\\ 0 & 0 & -1\\ 0 & 1 & 0 \end{pmatrix}
   \in SO(3),
\]
which yields
\begin{align*}
  b_1 &= (0,\,-1,\,0),\\
  b_2 &= \bigl(\tfrac{2\sqrt{2}}{3},\,\tfrac{1}{3},\,0\bigr),\\
  b_3 &= \bigl(-\tfrac{\sqrt{2}}{3},\,\tfrac{1}{3},\,\tfrac{\sqrt{6}}{3}\bigr),\\
  b_4 &= \bigl(-\tfrac{\sqrt{2}}{3},\,\tfrac{1}{3},\,-\tfrac{\sqrt{6}}{3}\bigr).
\end{align*}
A direct check shows that none of the $b_j$ is collinear with any
$a_i$, confirming that the eight rays are distinct.
\end{example}

\begin{proof}
The matrix $A=[a_1\;a_2\;a_3\;a_4]$ satisfies $AA^{T}=\tfrac{4}{3}I_3$
by direct computation, so $T=\tfrac{4}{3}I_3$.  Since $R\in O(3)$,
\[
  \sum_{j=1}^{4}P_{b_j}=R\Bigl(\sum_{j=1}^{4}P_{a_j}\Bigr)R^{T}
  =R\cdot\tfrac{4}{3}I_3\cdot R^{T}=\tfrac{4}{3}I_3,
\]
giving the common structure operator.  The hypothesis
$R\in SO(3)\setminus S^{*}$ excludes ray collisions, so the eight
rays are pairwise distinct.  Within the $a$-tuple, the inner products
$\langle a_i,a_j\rangle=-1/3\neq 0$ for $i\neq j$ show that no two
distinct vectors are orthogonal, so the tuple is not a context; the
$b$-tuple is its image under the orthogonal map $R$ and inherits
this property.  The pseudocontext is therefore genuine, in agreement
with Proposition~\ref{prop:rot_principle} specialised to $n=3$,
$k=4$.
\end{proof}

\begin{remark}[Orbit of a fixed tetrahedron]\label{rem:tetrahedron_family}
For the fixed tetrahedral frame in Example~\ref{ex:tetrahedron}, the family
obtained by varying $R\in SO(3)\setminus S^{*}$ is parametrized by an open
dense subset of $SO(3)$, modulo the finite tetrahedral symmetry group.
This is a 3-dimensional orbit of one fixed frame, not the full moduli space
of all size-4 tight frames in $\mathbb{R}^3$.
\end{remark}

\begin{remark}[Fixed-frame versus full moduli]
The tetrahedral example exhibits one particularly symmetric point in the
space of size-4 tight frames in $\mathbb{R}^3$. The point of the example
is only that this one orbit already yields a genuine pseudocontext spanning
all of $\mathbb{R}^3$.
\end{remark}

\begin{remark}[Physical interpretation]
A four-outcome rank-one POVM in $\mathbb{R}^3$ structured like a
tetrahedral measurement apparatus may be rotated rigidly by any
$R\in SO(3)$.  The rotated apparatus describes a physically distinct
set of nonorthogonal measurement directions, yet by
Example~\ref{ex:tetrahedron} the sum of single-outcome
probabilities coincides on every quantum state.  The pseudocontextual
identity at $k=4$ is therefore not an isolated algebraic accident
but a robust feature of the tetrahedral frame geometry.
\end{remark}

\begin{conjecture}[The tetrahedral pseudocontext is not graph-forced]
\label{conj:tetrahedron_not_graph_forced}
Let $(a_1,\ldots,a_4)$ and $(b_1,\ldots,b_4)=(Ra_1,\ldots,Ra_4)$
be the tetrahedral pseudocontext of Example~\ref{ex:tetrahedron},
with $R\in SO(3)\setminus S^{*}$.  Then the pseudocontextual
identity
\[
  \sum_{j=1}^{4}P_{a_j}=\sum_{j=1}^{4}P_{b_j}=\tfrac{4}{3}\,I_3
\]
is not graph-forced over $\mathbb{R}$: there is no finite
orthogonality hypergraph $\Gamma$ over $\mathbb{R}^3$ with vertex
set containing $\{[a_1],\ldots,[a_4],[b_1],\ldots,[b_4]\}$ such
that the closure conditions $\sum_{v\in C}P(v)=1$ for $C$ ranging
over the contexts of $\Gamma$ entail
$\sum_{j}P(a_j)=\sum_{j}P(b_j)$ via a covering argument of the type
employed in Section~\ref{s:octagon}, for any choice of
$R\in SO(3)\setminus S^{*}$ outside a measure-zero subset.
\end{conjecture}

\begin{remark}[Supporting evidence]
The eight rays $[a_1],\ldots,[a_4],[b_1],\ldots,[b_4]$ carry no
pairwise orthogonalities among themselves: within each tuple
$\langle a_i,a_j\rangle=\langle b_i,b_j\rangle=-\tfrac{1}{3}\neq0$
for $i\neq j$, and the cross-orthogonality locus
$\{R\in SO(3):\langle a_i,Ra_j\rangle=0\text{ for some }i,j\}$
is a positive-codimension subvariety of $SO(3)$.  The minimal
hypergraph extension that could cancel both tuples on a shared set
of auxiliaries requires eight extra unit vectors
$w_k\propto a_{i(k)}\times b_{j(k)}$ subject to eight cross-Gram
product conditions of the form
\[
  \langle a_i,b_{j_1}\rangle\,\langle a_i,b_{j_2}\rangle
  \;=\;-\tfrac{1}{3},
\]
arising from mutual orthogonality of the auxiliaries inside each
context.  These conditions are eight algebraic equations on the
nine entries of the cross-Gram matrix $G=A^{T}RA$, while
$R\in SO(3)$ contributes only three parameters; generically the
system is inconsistent, and the special loci where it is consistent
collapse onto $S^{*}$ itself, violating distinctness.  This
argument rules out the minimal embedding; the conjecture asserts
that the same rigidity persists for arbitrarily complex
extensions.
\end{remark}

\begin{remark}[Complex analogue]
Over $\mathbb{C}$ the parameter count flips: a rotation
$U\in U(3)$ has nine real parameters while the cross-Gram entries
$\langle a_i,Ub_j\rangle$ are complex.  The dimension argument
above does not apply, leaving open whether complex tetrahedral-type
pseudocontexts admit hypergraph-forcing extensions in
$\mathbb{C}^3$.
\end{remark}

\subsection{The tightness obstruction at $k=3$}

The rotation principle of Proposition~\ref{prop:rot_principle}
cannot be applied at $k=3$ in $\mathbb{R}^3$, because tightness in
this regime collapses to orthogonality.

\begin{proposition}\label{prop:k3_obstruction}
Let $(a_1,a_2,a_3)$ be a unit-norm tight frame in $\mathbb{R}^3$,
i.e.\ $T=I_3$.  Then $(a_1,a_2,a_3)$ is an orthonormal basis,
hence a context.
\end{proposition}

\begin{proof}
By Proposition~\ref{prop:trace},
$\operatorname{tr}(T^2)=k+\sum_{i\neq j}|\langle a_i,a_j\rangle|^2$.
With $T=I_3$ and $k=3$ this gives $3=3+\sum_{i\neq j}|\langle
a_i,a_j\rangle|^2$, forcing all off-diagonal Gram entries to vanish.
\end{proof}

\begin{corollary}\label{cor:k3_nondegenerate}
Every genuine real pseudocontext of size $k=3$ whose rays span all
of $\mathbb{R}^3$ has nondegenerate structure operator, and
therefore lies outside the rotational orbit construction of
Proposition~\ref{prop:rot_principle}.
\end{corollary}

Such genuinely three-dimensional, nondegenerate $k=3$
pseudocontexts do exist: explicit coordinatisations were obtained
in~\cite{2023-navara-svozil} (recalled in
Remark~\ref{rem:nondegenerate}), with structure operators having
spectra
\(\{2,\,(7+\sqrt{21})/14,\,(7-\sqrt{21})/14\}\) and
$\{1/5,1/5,13/5\}$ respectively.  These configurations are produced
not by acting on a single tight base configuration with a continuous
symmetry, but by solving the canonical fibre conditions of
Theorem~\ref{thm:canonical} directly with a prescribed nondegenerate
spectrum, the off-diagonal Gram data being constrained by an
underlying orthogonality hypergraph rather than recoverable from a
continuous group orbit.

\subsection{Larger sizes}

For every $k\ge 4$, unit-norm tight frames in $\mathbb{R}^3$ exist
in abundance, and Proposition~\ref{prop:rot_principle} produces a
$3$-parameter family of size-$k$ pseudocontexts whenever the chosen
frame has finite ray-stabiliser. Among the most symmetric examples we have the Platonic frames and their pyramid generalisations:
\begin{itemize}
  \item $k=4$: regular tetrahedron, $T=\tfrac{4}{3}I_3$
        (Example~\ref{ex:tetrahedron});
  \item $k=5$: a regular square pyramid whose four base vectors are elevated to angle $\arccos(1/\sqrt{6})$ from the apex, $T=\tfrac{5}{3}I_3$;
  \item $k=6$: one representative from each of the six antipodal
        vertex pairs of a regular icosahedron, $T=2I_3$;
  \item $k=7$: a regular hexagonal pyramid whose six base vectors are elevated to angle $\arccos(\sqrt{2}/3)$ from the apex, $T=\tfrac{7}{3}I_3$;
  \item \(k=12\): a union of three generically rotated tetrahedral tight
frames, chosen with no ray coincidences, gives \(T=4I_3\).
\end{itemize}

While Platonic solids naturally furnish perfectly symmetric (equiangular) frames for $k=4$ and $k=6$, the cases of $k=5$ and $k=7$ illustrate a fundamental structural phase shift. By Gerzon's bound, the maximum number of vectors in a real equiangular tight frame (ETF) in $\mathbb{R}^n$ is $\frac{1}{2}n(n+1)$, which caps at exactly $k=6$ for $\mathbb{R}^3$. Furthermore, real ETFs only exist for restricted sizes (namely $k=3, 4, 6$ in $\mathbb{R}^3$). Consequently, no strictly maximally symmetric configurations can exist for $k=5$ or $k\ge 7$.

However, to compensate for the loss of perfect symmetry, these non-ETF frames acquire internal degrees of freedom. Finite frame theory dictates that the unit-norm tight-frame variety in $\mathbb{R}^3$ modulo rotations has dimension $2k-8$. Thus, while $k=4$ represents a rigid shape, the highly symmetric ``square pyramid'' of $k=5$ actually sits within a $2$-parameter space of smoothly deforming tight frames (e.g., stretching into rectangular or rhombic pyramids), and the $k=7$ configuration inhabits a $6$-parameter deformation space. Each point in these continuous configuration spaces generates its own $3$-parameter rotational family of real pseudocontexts spanning $\mathbb{R}^3$.

\begin{remark}
Together with the planar Mercedes--Benz construction
(Example~\ref{ex:mb}) and the nondegenerate $k=3$ realisations in
$\mathbb{R}^3$ of \cite{2023-navara-svozil}
(cf.~Remark~\ref{rem:nondegenerate}), Example~\ref{ex:tetrahedron}
completes a coherent picture of real pseudocontexts in low ambient
dimension: every $k\ge 3$ admits genuine real realisations spanning
$\mathbb{R}^3$. Those for $k=3$ are necessarily nondegenerate
(Corollary~\ref{cor:k3_nondegenerate}), those for $k=4$ and $k=6$
admit highly rigid, rotationally parametrised ETF families, and those for $k \ge 5$ (lacking ETF structure) exist within continuous, multidimensional spaces of internally deforming tight realisations.
Numerical continuation confirms that unconstrained, purely vectorial $k=3$ pseudocontexts also exist in continuous deformations (e.g., with generic spectra such as $\lambda \approx \{0.68, 1.16, 1.16\}\approx (1/7) \{5,8,8\}$), though they lack the global rotational symmetry of the $k \ge 4$ tight frames.
\end{remark}

\begin{example}[Pyramidal tight frames for $k=5$ and $k=7$]
\label{ex:pyramids}
By Gerzon's bound~\cite[Theorem~3.5]{lemmens1973equiangular}, no real equiangular tight frame (ETF) can contain more than $\frac{1}{2}n(n+1)$ vectors, meaning no perfectly symmetric Platonic configuration can exist in $\mathbb{R}^3$ for $k=5$ or $k \ge 7$. Nonetheless, highly symmetric unit-norm tight frames can be constructed via regular pyramids.
For $k=5$, a tight frame with $T=\tfrac{5}{3}I_3$ is formed by a square pyramid with apex $v_1 = (0,0,1)$ and four base vectors at an angle of $\arccos(1/\sqrt{6})$ from the apex:
\[
    v_{2,3} = \bigg(\pm \sqrt{\frac{5}{6}}, 0, \frac{1}{\sqrt{6}}\bigg), \quad
    v_{4,5} = \bigg(0, \pm \sqrt{\frac{5}{6}}, \frac{1}{\sqrt{6}}\bigg).
\]
Similarly, for $k=7$, a tight frame with $T=\tfrac{7}{3}I_3$ is given by a hexagonal pyramid with apex $v_1=(0,0,1)$ and six base vectors at an angle of $\arccos(\sqrt{2}/3)$ from the apex:
\[
    v_{j+2} = \bigg(\frac{\sqrt{7}}{3}\cos\frac{j\pi}{3},\; \frac{\sqrt{7}}{3}\sin\frac{j\pi}{3},\; \frac{\sqrt{2}}{3}\bigg) \quad \text{for } j \in \{0, \dots, 5\}.
\]
Unlike the rigid ETFs at $k=4$ and $k=6$, parameter-counting reveals that the unit-norm tight-frame variety in $\mathbb{R}^3$ has $2k-8$ internal degrees of freedom (modulo rotations). Thus, these $k=5$ and $k=7$ pyramids represent highly symmetric points within $2$-parameter and $6$-parameter continuous spaces of deforming tight realisations, respectively.
\end{example}

\section{Open problems}
% ------------------------------------------------------------------

\begin{problem}[Classification over $\mathbb{C}^n$]
Classify, up to unitary equivalence, all pseudocontexts of size $k$
in $\mathbb{C}^n$.  Even for small $(k,n)$, the orbit structure is
not yet transparent.
\end{problem}

\begin{problem}[Lattice representability]
Characterise which orthomodular lattices carrying a
pseudocontext-type additive identification admit a faithful embedding
into some $L(\mathbb{C}^n)$, sharpening the partial results of
\cite{2023-navara-svozil,navara-2024-e}.
\end{problem}

\begin{problem}[Frame-symmetry characterisation in the partially
degenerate case]


For a positive operator \(T\) with spectral decomposition
\[
T=\sum_\alpha \lambda_\alpha P_\alpha,
\]
describe the decomposition space
\[
\mathcal D(T)=
\left\{
(a_1,\ldots,a_k):
\sum_i P_{a_i}=T,\ \|a_i\|=1
\right\}
\]
modulo column phases, permutations, and the commutant
\[
\prod_\alpha U(\operatorname{rank}P_\alpha).
\]
In particular, determine the commutant-orbit strata and the residual
moduli of inequivalent decompositions for partially degenerate spectra.
\end{problem}

\begin{problem}[Hypergraph-forced higher-dimensional pseudocontexts]
The rotation construction of Section~\ref{sec:3d_real} produces continuous families of
operator-level pseudocontexts spanning all of \(R^n\). In generic examples,
such as the tetrahedral family, there is strong
evidence that the identity is not graph-forced by a finite orthogonality
hypergraph.
In contrast, in
\cite{2023-navara-svozil,navara-2024-e} and in
Section~\ref{s:octagon} of the present paper, the orthogonality
relations themselves induce condition~(iii) of
Definition~\ref{def:pc} for every vector representation fulfilling
the orthogonality constraints.  The systematic classification of
hypergraphs that force a pseudocontext identity, and of the
higher-dimensional configurations they admit, remains open.  This
stratum is disjoint from the one resolved in
Section~\ref{sec:3d_real}: the tetrahedral example is not a
graph-forced pseudocontext, since the topological covering technique
of Section~\ref{sec:loose_ends} cannot be applied to it.
\end{problem}

\begin{problem}[Classification of minimal real pseudocontexts]
Theorem~\ref{thm:d2_real_complex}(ii) and the proposition that follows
it (Proposition~\ref{prop:no_real_k2_anyn}) establish that genuine real
pseudocontexts of size $k=2$ do not exist in any dimension, while
Example~\ref{ex:mb} demonstrates their existence for $k=3$ in
two-dimensional subspaces and \cite{2023-navara-svozil} exhibits
$\mathbb{R}^3$-spanning instances.  Thus $k=3$ is the minimal size
for genuine real pseudocontexts.  Classify all such minimal
($k=3$) examples up to orthogonal equivalence over $\mathbb{R}$,
distinguishing the two-dimensional case (where the doubled-angle
projective-circle description reduces the problem to equal-centroid
decompositions of three unit vectors, with scalar structure operators
only in the zero-centroid tight-frame subcase) from the genuinely
three-dimensional case (where, by
Corollary~\ref{cor:k3_nondegenerate}, the structure operator is
necessarily nondegenerate).
\end{problem}

\begin{problem}[Moduli of tight real pseudocontexts]
For each $k\ge n+1$, describe the moduli space
\(
  \mathcal{M}_{k,n}^{\mathrm{tight}}
  =\bigl\{\text{unit-norm tight frames of size $k$ in $\mathbb{R}^n$}\bigr\}
   \big/ O(n)\times S_k,
\)
where $S_k$ acts by permutation.  Together with
Proposition~\ref{prop:rot_principle}, an explicit description of
$\mathcal{M}_{k,n}^{\mathrm{tight}}$ would yield a complete
parametrisation of the tight stratum of real $\mathbb{R}^n$-spanning
pseudocontexts of size $k$.  The case $(k,n)=(4,3)$ reduces to a
point (the regular tetrahedron, by Example~\ref{ex:tetrahedron});
$(k,n)=(5,3)$ already gives a positive-dimensional moduli space.
\end{problem}

\section{Derivation of the Master Constraint}
\label{app:master_derivation}

We provide a step-by-step verification of the algebraic derivation
leading from the perimeter closure conditions to the master
constraint~\eqref{eq:master} used in the proof of
Proposition~\ref{prop:no_real_C1}.

The starting point is the perimeter closure condition stated in the
proof: for three rays $v_{j-1}, v_j, v_{j+1}$ forming a context,
adjacent corner rays are orthogonal, yielding
\begin{equation}
(v_{j-1}\cdot v_j)(v_j\cdot v_{j+1})-(v_{j-1}\cdot v_{j+1})\|v_j\|^2=0.
\label{eq:closure_condition}
\end{equation}
Evaluating~\eqref{eq:closure_condition} at $j=0$ and $j=4$ produces
the relations
\begin{align}
Y_0 &= \frac{Y_7+mX_1}{1-mX_1Y_7}, \label{eq:Y0_app} \\
Y_4 &= \frac{Y_3+mX_5}{1-mY_3X_5}, \label{eq:Y4_app}
\end{align}
as stated in the proof. The inner contexts impose the constraints
\begin{equation}
Y_7 = -\frac{1}{MY_3},\qquad
X_5 = -\frac{1}{MX_1},\qquad
M = 1+m^2,
\label{eq:inner_constraints_app}
\end{equation}
together with the requirement $Y_0Y_4 = -1$ from context $D_0$.

\subsection*{Simplifying the fractions}

Substituting $Y_7$ from~\eqref{eq:inner_constraints_app} into~\eqref{eq:Y0_app}:
\begin{align}
Y_0 &= \frac{-\frac{1}{MY_3}+mX_1}{1-mX_1\bigl(-\frac{1}{MY_3}\bigr)}
     = \frac{mMX_1Y_3-1}{MY_3+mX_1}. \label{eq:Y0_simplified}
\end{align}
Substituting $X_5$ from~\eqref{eq:inner_constraints_app} into~\eqref{eq:Y4_app}:
\begin{align}
Y_4 &= \frac{Y_3+m\bigl(-\frac{1}{MX_1}\bigr)}{1-mY_3\bigl(-\frac{1}{MX_1}\bigr)}
     = \frac{MX_1Y_3-m}{MX_1+mY_3}. \label{eq:Y4_simplified}
\end{align}

\subsection*{Constructing the product condition}

Let $u = X_1Y_3$. Using the constraint $Y_0Y_4 = -1$ from context
$D_0$ together with~\eqref{eq:Y0_simplified} and~\eqref{eq:Y4_simplified}:
\begin{equation}
\frac{mMu-1}{mX_1+MY_3}\cdot\frac{Mu-m}{MX_1+mY_3} = -1.
\label{eq:product_condition}
\end{equation}
Cross-multiplying~\eqref{eq:product_condition} yields
\begin{equation}
(mMu-1)(Mu-m) = -(mX_1+MY_3)(MX_1+mY_3).
\label{eq:cross_multiplied}
\end{equation}

\subsection*{Expanding both sides}

The left-hand side of~\eqref{eq:cross_multiplied} expands as
\begin{align}
\text{LHS} &= mM^2u^2 - m^2Mu - Mu + m \nonumber\\
           &= mM^2u^2 - Mu(m^2+1) + m. \label{eq:LHS_expanded}
\end{align}
Since $M = 1+m^2$, the coefficient $m^2+1$ equals $M$, giving
\begin{equation}
\text{LHS} = mM^2u^2 - M^2u + m.
\label{eq:LHS_final}
\end{equation}

The right-hand side of~\eqref{eq:cross_multiplied} expands as
\begin{align}
\text{RHS} &= -\bigl[mMX_1^2 + m^2X_1Y_3 + M^2X_1Y_3 + mMY_3^2\bigr] \nonumber\\
           &= -\bigl[u(M^2+m^2) + mM(X_1^2+Y_3^2)\bigr].
\label{eq:RHS_final}
\end{align}

\subsection*{Cancellation and the master constraint}

Equating~\eqref{eq:LHS_final} and~\eqref{eq:RHS_final}:
\begin{equation}
mM^2u^2 - M^2u + m = -u(M^2+m^2) - mM(X_1^2+Y_3^2).
\label{eq:equated}
\end{equation}
Adding $M^2u$ to both sides, the $-M^2u$ term cancels:
\begin{equation}
mM^2u^2 + m = -m^2u - mM(X_1^2+Y_3^2).
\label{eq:cancelled}
\end{equation}
Bringing all terms to the left and dividing by $m \neq 0$ (since
$\theta \notin \frac{\pi}{2}\mathbb{Z}$ by faithfulness) yields the
master constraint~\eqref{eq:master} in the proof of Proposition~\ref{prop:no_real_C1}.

\subsection*{Positivity contradiction}

Since $X_1,Y_3 \in \mathbb{R}$, the inequality
$X_1^2+Y_3^2 \geq 2|X_1Y_3| = 2|u|$ holds. The left-hand side
of~\eqref{eq:master} therefore satisfies
\begin{align}
&M^2u^2 + mu + 1 + M(X_1^2+Y_3^2) \nonumber\\
  &\geq M^2u^2 + mu + 1 + 2M|u| \nonumber\\
  &\geq M^2u^2 + |u|(2M - |m|) + 1.
\label{eq:bounded}
\end{align}
With $M = 1+m^2 > 1$, we have
$2M - |m| = 2+2m^2-|m| > 0$ for all real $m$. Consequently the
expression in~\eqref{eq:bounded} is strictly positive for every
$u \in \mathbb{R}$, contradicting~\eqref{eq:master}. This
completes the algebraic verification of the master constraint and
the resulting impossibility of a real realization.

\section{Set representation of the octagon hypergraph via two-valued states}
\label{app:set_representation}

As described in Section 2.3 of Ref.~\cite{svozil-2001-eua}, any finite atomic logic equipped with a separating set of dispersion-free probability measures (two-valued states) can be faithfully represented as a partition logic~\cite{ZirlSchl-65,greechie-66-PhD,kochen1}.
In this formulation, the set representation is constructed by ``inverting'' the set of two-valued states: every vertex $v$ (atom) of the hypergraph is mapped to the set of indices of those two-valued states that evaluate to $1$ (``true'') on it.
Explicitly, if $M$ denotes the complete set of two-valued states $s_k$, the set representation of a vertex $v$ is given by
\begin{equation}
    p(v) = \{k \mid s_k(v) = 1, \, k \in M\}.
\end{equation}
Under this mapping, every context (orthogonal basis) translates into a disjoint partition of the total state space $M$.

\subsection{Comparison of deterministic, classical, and quantum probability sums}
\label{app:classical_quantum_comparison}

The indicator or characteristic function
\(\mathbf 1_A(x)=1\) if \(x \in A\) and \(0\) if \(x \not\in A\).
For a vertex \(v\), write
\[
s_i(v)=\mathbf 1_{p(v)}(i),
\]
where \(p(v)=\{i:s_i(v)=1\}\) is its support in the Travis representation.

The equality
\[
p(a_1)\cup p(a_2)=p(b_1)\cup p(b_2)
\]
therefore says only that the two pairs have the same support for the
corresponding logical OR. It does not, by itself, imply equality of the
arithmetic sums of truth values. Indeed, for two Boolean variables \(x,y\),
\[
x+y=(x\vee y)+(x\wedge y).
\]
Equivalently, for indicator (characteristic) functions,
\[

full Travis matrix, or derived from the context-covering equations of
Section~\ref{s:octagon}, not as a consequence of union equality alone.

\[

\]

\(0,2\) in the full \(C=1\) configuration. For classical hidden-variable
mixtures over the enumerated two-valued states,
\[
P_{\rm cl}(v)=\sum_i \lambda_i s_i(v),\qquad
\lambda_i\ge 0,\qquad \sum_i\lambda_i=1,
\]
the four-term sum is no longer restricted to these discrete values, but
ranges over their convex hull: \([0,4]\) in the incomplete case and
\([0,2]\) in the full \(C=1\) case.

On the quantum side, the corresponding equality is expressed by the
structure operator
\[
T=P_{a_1}+P_{a_2}=P_{b_1}+P_{b_2}.
\]
Hence
\[
P_Q(a_1)+P_Q(a_2)+P_Q(b_1)+P_Q(b_2)
=
2\,\operatorname{tr}(\rho T).
\]
For a two-dimensional support \(V\), the \(k=2\) Bloch representation gives
\[
T=I_V+\frac12 \vec R\cdot \vec\sigma,
\]
with eigenvalues
\[
\lambda_\pm=1\pm \frac12\|\vec R\|.
\]
Thus the maximal quantum four-term sum is
\[
2\lambda_{\max}(T)=2+\|\vec R\|.
\]
In the incomplete nonorthogonal case, \(\vec R\neq 0\), so this maximum is
larger than \(2\), but still strictly below the deterministic classical
maximum \(4\) unless the two rays collapse. In the full \(C=1\) case,
orthogonality forces \(\vec R=0\), so
\[
T=I_V.
\]
Since $\{a_1,c,a_2\}$ is a context in the full \(C=1\)
configuration, $P_{a_1}+P_c+P_{a_2}=I$, giving $T=I-P_c$.
Consequently,
\[
0\le 2\,\operatorname{tr}(\rho T)\le 2,
\]
with equality \(2\) for states supported entirely on \(V=c^\perp\). Thus
the added contexts remove the deterministic classical excess \(4\) and
bring the classical convex bound for the four-term sum into agreement
with the quantum spectral bound.

import numpy as np
from scipy.optimize import minimize

def build_matrices(params, k):
    """Unpacks the 1D parameter array into matrices A and U."""
    # 1. Unpack spherical coordinates for A
    theta = params[0:k]
    phi = params[k:2*k]

    A = np.array([
        np.sin(theta) * np.cos(phi),
        np.sin(theta) * np.sin(phi),
        np.cos(theta)
    ])

    # 2. Unpack the skew-symmetric matrix S for U
    # A skew-symmetric matrix has zeros on the diagonal and S^T = -S
    # It requires exactly k*(k-1)/2 parameters.
    S = np.zeros((k, k))
    s_params = params[2*k:]

    idx = 0
    for i in range(k):
        for j in range(i+1, k):
            S[i, j] = s_params[idx]
            S[j, i] = -s_params[idx]
            idx += 1

    # Cayley Transform: U = (I - S)(I + S)^-1
    I = np.eye(k)
    U = np.linalg.inv(I + S) @ (I - S)

    return A, U

def objective_function(params, k):
    """The loss function we want to minimize."""
    A, U = build_matrices(params, k)

    # Construct B
    B = A @ U

    # Objective 1: Columns of B must have a norm of 1
    B_norms_sq = np.sum(B**2, axis=0)
    loss_norm = np.sum((B_norms_sq - 1.0)**2)

    # Objective 2: Distinctness (No ray in A can be identical to a ray in B)
    # C_ij = dot product of a_i and b_j. If |C_ij| is close to 1, penalize heavily.
    C_matrix = A.T @ B
    loss_distinct = np.sum(np.exp(10 * (np.abs(C_matrix) - 0.95)))

    return loss_norm + 0.1 * loss_distinct

def solve_pseudocontext(k=4):
    # Calculate the number of parameters needed
    # 2*k for angles, k*(k-1)/2 for the skew-symmetric matrix
    num_s_params = k * (k - 1) // 2
    total_params = 2 * k + num_s_params

    # Initial random guess
    initial_guess = np.random.randn(total_params)

    print(f"Running optimizer for k={k}...")

    # Run the BFGS optimizer
    result = minimize(
        objective_function,
        initial_guess,
        args=(k,),
        method='BFGS',
        options={'disp': True, 'maxiter': 5000}
    )

    A_res, U_res = build_matrices(result.x, k)

    eigenvalues = np.linalg.eigvals(T)
    print("\nEigenvalues of Structure Operator T:")
    print(np.sort(np.real(eigenvalues)))

    return A_res, B_res, T

We were trying to find an orthogonal matrix $U$ in 4D space to mix the vectors. But look at the definition of a Tight Frame: its structure operator is perfectly proportional to the Identity matrix ($T = \frac{4}{3}I$).

In quantum mechanics, the Identity matrix is rotationally invariant. **This means if you take a tetrahedral measurement apparatus and physically rotate the entire thing in 3D space, its structure operator does not change!** $R (\frac{4}{3}I) R^T = \frac{4}{3}I$.

We don't need a massive $4 \times 4$ matrix solver. We just need to find a standard 3D spatial rotation (like rotating a physical object in your hands) that moves the tetrahedron so that its new rays don't overlap with its old rays.

Here is the ultimate, simplified solver. It drops the random 4D math and uses a deterministic 3D geometric optimizer to find the perfect spatial rotation. It will execute perfectly:

```python
import numpy as np
from scipy.optimize import minimize
from scipy.spatial.transform import Rotation as R_scipy

def construct_observables(angles):
    """Rotates the quantum tetrahedron in 3D space using Euler angles."""
    # The perfect analytical Tetrahedron (A)
    A = np.array([[0, np.sqrt(8/9), -np.sqrt(2/9), -np.sqrt(2/9)],[0, 0, np.sqrt(2/3), -np.sqrt(2/3)],
        [1, -1/3, -1/3, -1/3]
    ])

    # Generate the 3D rotation matrix
    R_mat = R_scipy.from_euler('xyz', angles).as_matrix()

    # The cloned tetrahedron (B)
    B = R_mat @ A

    return A, B

def overlap_loss(angles):
    """We want to minimize the maximum overlap between the original and rotated rays."""
    A, B = construct_observables(angles)
    C_matrix = A.T @ B
    return np.max(np.abs(C_matrix))

print("Hunting for the optimal 3D spatial rotation to clone the Quantum Tetrahedron...\n")

best_overlap = 1.0
best_A, best_B = None, None

# Run the geometric optimizer from 10 random starting orientations
for attempt in range(10):
    initial_angles = np.random.uniform(0, 2*np.pi, 3)
    res = minimize(overlap_loss, initial_angles, method='Nelder-Mead')

    if res.fun < best_overlap:
        best_overlap = res.fun
        best_A, best_B = construct_observables(res.x)

print(f"? ROTATION FOUND!")
print(f"Max Overlap |a_i * b_j|: {best_overlap:.4f}")

if best_overlap < 0.999:
    print("\n--- THIS IS A GENUINE TIGHT PSEUDOCONTEXT ---")

    # 1. Verify Distinctness
    print("Distinctness verified: No ray in B overlaps with A.")

    # 2. Verify Norms
    norms = np.sum(best_B**2, axis=0)
    print("B column norms:      ", np.round(norms, 6))

    # 3. Verify the Tight Frame Property
    T_A = best_A @ best_A.T
    T_B = best_B @ best_B.T
    print("Eigenvalues of T_A:  ", np.round(np.linalg.eigvals(T_A), 6))
    print("Eigenvalues of T_B:  ", np.round(np.linalg.eigvals(T_B), 6))

else:
    print("Failed to find distinct rays.")
```
