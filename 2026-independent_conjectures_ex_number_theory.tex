\title{Independent Non-Redundant Open Conjectures Outside Number Theory\\
79 Problems After Collapsing Implications and Disproved Cases}
\author{Compilation from 100-item list}
\affiliation{Mesh analysis}
\date{\today}

\begin{abstract}
From a 100-item list of open conjectures outside number theory we remove duplicates, resolved and disproved cases, and implication chains. Duplicates: sphere packing in $5\!-\!7\subset$ general Kepler, Willmore higher genus $=$ Willmore generalizations, Hadwiger-Nelson adjacent $=$ chromatic number of plane, Erdos-Szekeres appears twice, Farrell-Jones appears twice. Implications: Farrell-Jones $\Rightarrow$ Borel, Baum-Connes, Novikov, Kaplansky idempotent; Zeeman $\Rightarrow$ Andrews-Curtis. Resolved/disproved: Telescope Conjecture disproved 2023, Borsuk disproved Kahn-Kalai, Hedetniemi disproved Shitov 2019, Connes Embedding refuted MIP*=RE 2020, Serre Galois proved Khare-Wintenberger, Virtually Haken and Property P proved. Remaining 79 are pairwise independent.
\end{abstract}

\maketitle

\section{Reduction}
\begin{itemize}
\item Keep strongest in each chain: Farrell-Jones, Zeeman, Kepler general, Firoozbakht analog not present here.
\item Drop special cases: $5\!-\!7$ sphere packing, Willmore duplicate, Hadwiger-Nelson adjacent, Erdos-Szekeres duplicate, Farrell-Jones duplicate.
\item Exclude disproved/proved: Telescope, Borsuk original, Hedetniemi original, Connes Embedding, Serre, Virtually Haken core, Property P core, Property R vague.
\end{itemize}

\section{Independent 79}

\begin{enumerate}[label={\bf \arabic*.}, leftmargin=*, itemsep=2pt]

\item \textbf{Smooth 4D Poincar\'e:} Every smooth homotopy $4$-sphere diffeomorphic to $S^4$.

\item \textbf{Zeeman Collapsibility:} If $K$ is contractible $2$-complex then $K\times I$ collapsible. Implies Andrews-Curtis.

\item \textbf{Hilbert-Smith:} No $p$-adic group acts effectively on a manifold.

\item \textbf{Farrell-Jones:} $K_*,L_*$ of group rings computed by $E_{VC}G$. Implies Borel, Novikov, Baum-Connes, Kaplansky idempotent.

\item \textbf{Slice-Ribbon:} Every slice knot in $S^3$ ribbon.

\item \textbf{Cabling Conjecture:} Dehn surgery yielding reducible manifold only for cable knots.

\item \textbf{Berge Conjecture:} Classification of knots admitting lens space surgeries.

\item \textbf{Effective Virtually Haken:} Quantitative versions of Agol's theorem remain open.

\item \textbf{Simple Loop Conjecture:} Non-injective $\pi_1$ map $\Sigma\to M^3$ has essential simple loop in kernel.

\item \textbf{Unknotting Number Additivity:} $u(K_1\#K_2)=u(K_1)+u(K_2)$.

\item \textbf{Kneser-Poulsen:} Moving centers of balls closer does not increase volume of union.

\item \textbf{Kepler-type general:} Optimal sphere packing density in $\mathbf R^n$ unknown for most $n\neq3,8,24$.

\item \textbf{Kissing Number:} Max number unit spheres touching unit sphere in $\mathbf R^n$, exact only for few $n$.

\item \textbf{Willmore generalizations:} Minimal Willmore energy for genus $>1$ and higher codimension, torus case proved Marques-Neves.

\item \textbf{Carath\'eodory:} Convex $C^2$ sphere in $\mathbf R^3$ has $\ge2$ umbilics.

\item \textbf{Yau First Eigenvalue:} Closed embedded minimal hypersurface in $S^{n+1}$ has $\lambda_1=n$.

\item \textbf{Bellman Lost in Forest:} Optimal worst-case escape path from forest of unknown shape.

\item \textbf{Moving Sofa:} Maximal area shape navigating unit-width L-corridor.

\item \textbf{Square Peg / Toeplitz:} Every Jordan curve contains 4 points forming a square.

\item \textbf{Erd\H{o}s-Szekeres:} Minimal $N(n)$ points forcing convex $n$-gon is $2^{n-2}+1$.

\item \textbf{Illumination:} Every convex body in $\mathbf R^n$ illuminable by $2^n$ light sources.

\item \textbf{Kakeya:} Besicovitch set containing unit segment in every direction has Hausdorff dimension $n$.

\item \textbf{Unit Distance:} Max number unit distances among $n$ points in plane, conjectured $n^{1+o(1)}$.

\item \textbf{Distinct Distances exact constant:} Guth-Katz $\Omega(n/\log n)$, exact constant open.

\item \textbf{Chromatic Number of Plane:} $\chi(\mathbf R^2)\in\{5,6,7\}$.

\item \textbf{Danzer's Problem:} Bounded-density set in $\mathbf R^2$ meeting every convex body of area $1$?

\item \textbf{Ulam Packing:} No convex body packs $\mathbf R^3$ more efficiently than sphere.

\item \textbf{Reinhardt:} Smoothed octagon is least efficient centrally symmetric convex shape packing plane.

\item \textbf{Non-spherical Kepler:} Optimal packing density for most convex bodies unknown.

\item \textbf{Bang Plank complex:} Covering convex body by planks, complex version open.

\item \textbf{Erd\H{o}s-Oler:} Optimal packing of $n(n+1)/2$ equal circles in equilateral triangle.

\item \textbf{Falconer Distance Set:} If $\dim_H E>1$ in $\mathbf R^2$, distance set has positive measure.

\item \textbf{Zarankiewicz:} Crossing number of $K_{m,n}$ equals $\lfloor m/2\rfloor\lfloor(m-1)/2\rfloor\lfloor n/2\rfloor\lfloor(n-1)/2\rfloor$.

\item \textbf{Hadwiger:} $\chi(G)\le\eta(G)$, chromatic number $\le$ size of largest clique minor.

\item \textbf{Erd\H{o}s-Faber-Lov\'asz:} $n$ cliques pairwise intersecting $\le1$ vertex need $n$ colors. Large $n$ proved 2021, full still debated.

\item \textbf{Total Coloring:} $\chi''(G)\le\Delta(G)+2$.

\item \textbf{List Coloring:} List edge chromatic number $=\chi'(G)$.

\item \textbf{Reconstruction:} Graph $\ge3$ vertices determined by multiset of vertex-deleted subgraphs.

\item \textbf{Edge Reconstruction:} Same for edge-deleted subgraphs.

\item \textbf{Cycle Double Cover:} Every bridgeless graph has collection of cycles covering each edge twice.

\item \textbf{Erd\H{o}s-Gallai cycle covers:} Edges of $n$-vertex graph coverable by $O(n)$ cycles?

\item \textbf{Barnette:} Every cubic $3$-connected planar bipartite graph Hamiltonian.

\item \textbf{Chv\'atal Toughness:} Every $3/2$-tough graph Hamiltonian.

\item \textbf{Erd\H{o}s-Hajnal:} For fixed $H$, $H$-free $n$-vertex graph has clique or independent set $\ge n^{c(H)}$.

\item \textbf{Union-Closed / Frankl:} In union-closed family $\neq\{\emptyset\}$, some element in $\ge1/2$ sets.

\item \textbf{Ryser:} For $r$-partite $r$-uniform hypergraph, $\tau\le(r-1)\nu$.

\item \textbf{EKR extensions:} Exact extremal families for general set systems beyond proven cases.

\item \textbf{Chromatic Symmetric Function:} For $(3+1)$-free poset, $X_G$ is $e$-positive.

\item \textbf{Tuza:} $\tau_t\le2\nu_t$ for triangle packing vs covering.

\item \textbf{Sidorenko:} For bipartite $H$, $t(H,G)\ge t(K_2,G)^{e(H)}$.

\item \textbf{Graceful Tree:} Every tree has graceful labeling $0..m$ with distinct edge differences.

\item \textbf{Erd\H{o}s-Gallai path:} $n$-vertex graph with $>n(k-1)/2$ edges contains path with $k$ edges.

\item \textbf{1/3-2/3 Conjecture:} Every non-total poset has pair with $1/3\le P(x<y)\le2/3$ in random linear extensions.

\item \textbf{Rota's Basis:} $n$ bases of rank $n$ matroid can be arranged in $n\times n$ grid where rows and columns are bases.

\item \textbf{Aharoni-Berger:} $n$ matchings size $n+1$ in bipartite graph have rainbow matching size $n$.

\item \textbf{Sunflower exact bound:} Sharp bound on size of $k$-uniform family with no $w$-sunflower.

\item \textbf{Erd\H{o}s-S\'os:} Graph average degree $>k-1$ contains every tree with $k$ edges.

\item \textbf{Vizing Domination:} $\gamma(G\square H)\ge\gamma(G)\gamma(H)$.

\item \textbf{Alon-Tarsi:} Even $n$ Latin squares: number even $\neq$ number odd, implies list coloring conjectures.

\item \textbf{Smale Mean Value:} $\min_{p'(c)=0}|p(c)/((c-z_0)p'(z_0))|\le1$ for polynomial $p$.

\item \textbf{Arnold Fixed Point:} Hamiltonian symplectomorphism has $\ge$ sum Betti numbers fixed points.

\item \textbf{Weinstein general:} Reeb vector field on closed contact manifold has periodic orbit, open beyond dim $3$.

\item \textbf{Palis:} Every dynamical system approximable by hyperbolic or with homoclinic tangency.

\item \textbf{Shub Entropy:} $h_{\text{top}}(f)\ge\log\rho(f_*)$.

\item \textbf{Zimmer Program:} Higher rank lattice actions on manifolds essentially algebraic.

\item \textbf{MLC:} Mandelbrot set locally connected.

\item \textbf{Fatou:} Hyperbolic rational maps dense in space of rational maps.

\item \textbf{Furstenberg $\times2\times3$:} Ergodic $\times2,\times3$-invariant measure on circle is Lebesgue or atomic.

\item \textbf{Banach $L^p$ classification:} Isomorphic classification of $L^p$ spaces remains incomplete.

\item \textbf{Invariant Subspace Hilbert:} Every bounded operator on separable Hilbert space has non-trivial closed invariant subspace.

\item \textbf{Berry-Tabor:} Generic integrable quantum system spectral statistics Poissonian.

\item \textbf{Quantum Unique Ergodicity general:} Arithmetic case proved Lindenstrauss, general manifolds open.

\item \textbf{Jacobian:} Polynomial map $\mathbf C^n\to\mathbf C^n$ with constant non-zero Jacobian determinant has polynomial inverse.

\item \textbf{Zariski Cancellation:} If $X\times\mathbf A^1\cong\mathbf A^{n+1}$ over $\mathbf C$, then $X\cong\mathbf A^n$, open for $n=3$.

\item \textbf{Bass Conjecture:} $K_0$ of group ring finitely generated.

\item \textbf{Quillen-Lichtenbaum:} $K$-theory of number fields relates to \'etale cohomology beyond proven range.

\item \textbf{Deligne Special Values:} Critical values of motivic $L$-functions are periods up to algebraic factor.

\item \textbf{Homological Mirror Symmetry:} Derived Fukaya category equivalent to derived category of coherent sheaves of mirror, general case open.

\item \textbf{Green Syzygies:} Clifford equals gonality for canonical curve, generic case proved Voisin, special cases open.

\end{enumerate}
