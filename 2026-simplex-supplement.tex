\section{Implemented orthant-factorization problem}

Real symmetric operators are represented by coordinates whose trace metric is
\[
G=\operatorname{diag}(\underbrace{1,\ldots,1}_{d},
\underbrace{2,\ldots,2}_{d(d-1)/2}).
\]
Effects are stored in dual coordinates $\widetilde I_E=GI_E$.  After quotienting
operational null directions and reducing to accessible coordinates, the
program computes homogeneous facet matrices $H_\Omega,H_E$ and solves
\[
H_E^T\sigma H_\Omega=
\widetilde I_E^T\bigl[(1-r)\Id+rD\bigr]I_\Omega,
\qquad \sigma\ge0,\qquad 0\le r\le1,
\]
where $D$ maps every normalized preparation to the maximally mixed state.
For a general operational rank factorization of a Born table, the same equation
is written in the induced rational or numerical coordinates.

The associated ontological normalization requirements are
\[
\sum_\lambda\mu_\omega(\lambda)=1,
\qquad \xi_u(\lambda)=1,
\qquad 0\le\xi_e(\lambda)\le1.
\]
Thus the implemented test is the general finite orthant-factorization test, not
an assumption that an intermediate simplicial cone has the accessible-space
dimension.

\subsection{Exact certificate convention}

Put
\[
M_0=\widetilde I_E^TI_\Omega,
\qquad M_1=\widetilde I_E^T(D-\Id)I_\Omega,
\]
and let $C_{\ell k}=(h^E_\ell)^Th^\Omega_k$.  An exact primal certificate is a
rational nonnegative matrix $\sigma$ satisfying
\[
\sum_{\ell,k}\sigma_{\ell k}C_{\ell k}-rM_1=M_0.
\]
An exact dual certificate is a rational matrix $Y$ satisfying
\[
\langle Y,C_{\ell k}\rangle\le0,
\qquad -\langle Y,M_1\rangle\le1,
\qquad \langle Y,M_0\rangle=r.
\]
The label ``exact optimum'' is used only when both certificates pass exact
rational verification.  A decimal approximation or a rationalization of a
floating-point optimum is labelled numerical.

\section{Reproduction and checkpoint use}

With NumPy, SciPy, SymPy, and a rational/GMP-enabled pycddlib installation,
the complete command is
\begin{verbatim}
python simplex_audit_rebuilt.py --outdir audit_v3
\end{verbatim}
The same command may be issued after an interruption or on a populated output
directory.  A task is reused only when its stored SHA-256 input fingerprint and
audit-schema version match.  The run log prints \texttt{REUSE} for such a task.
To request every calculation explicitly, use
\begin{verbatim}
python simplex_audit_rebuilt.py --outdir audit_v3 --force
\end{verbatim}
Validation-only and selected-configuration runs are available through
\texttt{--validate} and repeatable \texttt{--only} arguments.
